Костя собирает турнир

ProTeam выпустила свою первую игру — космический шутер «SpaceShooter». Игра разошлась по школам, и Костя решил устроить турнир между командами.

👨‍💻
Привет, Байт! Игроки из разных школ хотят посоревноваться. Мне нужно три программы для турнира: первая — принимать заявки от команд, вторая — хранить результаты всех раундов, третья — считать, кто победил.
🤖
Знакомая задача! Раньше я для хранения данных заводил переменные — a, b, c. Но тут команд много, десятки. Что делать — заводить переменную для каждой?
👩‍💼
Не надо! В Python есть список — специальный тип данных, который хранит много значений вместе. Сегодня разберём все его команды. Начнём с самого простого.
Список (list)
Это структура данных, которая хранит упорядоченный набор значений. Каждое значение имеет свой номер — индекс.
results = [181, 176, 160, 178] — список из четырёх чисел.
names = ['Аня', 'Боря', 'Вика'] — список из трёх строк.
🧠 Зачем нужны списки

Список — это как полка с ячейками. На каждой ячейке своё значение. У каждой ячейки есть номер — можно взять любую, не заводя для каждой отдельную переменную.

На одной полке могут храниться значения разных типов: числа, строки, даже другие списки.

🤖
Отлично! Тогда идём по порядку: как создать список, как добавить в него данные, как их найти, отсортировать и посчитать. Костя будет подкидывать задачи, а я — решать.

Кто победил в турнире?

Турнир прошёл. У аналитиков — список результатов всех команд. Нужно посчитать средний балл и найти победителя.

👨‍💻
Список готов: [225, 220, 199, 263, 259, 225, 226]. Нужно: посчитать средний результат и найти максимальный. Думаю, тут без перебора элементов не обойтись.
10 for result in results:
Что делает

Перебирает элементы списка. На каждой итерации переменная result получает следующий элемент из списка. Знакомая команда for, только теперь для списка, а не для строки.

🔁
Аналогия

Ты идёшь по списку покупок по одному пункту и что-то с каждым делаешь: берёшь, читаешь, кладёшь в корзину.

results = [181, 176, 160] for result in results: print('Результат команды:', result) # Результат команды: 181 # Результат команды: 176 # Результат команды: 160
11 sum, max, min, len
Что делает

Python уже умеет считать сумму, максимум, минимум и длину списка. Эти команды называются встроенными функциями — их не нужно писать самому.

results = [225, 220, 199, 263] print(sum(results)) # 907 print(max(results)) # 263 print(min(results)) # 199 print(len(results)) # 4
🤖
Соединим всё вместе: перебираем результаты в цикле, считаем сумму и находим максимум.
results = [225, 220, 199, 263, 259, 225, 226] total = 0 max_result = 0 for r in results: total += r if r > max_result: max_result = r average = total / len(results) print('Результаты:', results) print('Средний результат:', average) print('Максимум:', max_result)
Что выведет программа
Результаты: [225, 220, 199, 263, 259, 225, 226]
Средний результат: 231.0
Максимум: 263
🧠 Простая версия

Благодаря встроенным функциям, тот же результат можно получить короче:

print('Средний:', sum(results) / len(results))
print('Максимум:', max(results))

Но умение перебирать элементы в цикле пригодится, когда задача сложнее — например, «сколько команд набрали больше 200 очков».

Две полезные команды напоследок

Ещё пара команд, которые часто выручают: разбить строку на список и защитить список от случайных изменений.

12 data.split(' ')
Что делает

Разбивает строку на список по разделителю. В скобках — символ, по которому режем строку.

✂️
Аналогия

Строка «220 211 198» — это как фраза, где слова разделены пробелами. split её «разрезает» по пробелам и складывает слова в список.

if int(r) > 200:

13 score = (34, 22, 79)
Что делает

Создаёт кортеж — «замороженный» список. Его элементы нельзя менять: ни добавить, ни удалить.

🔒
Аналогия

Обычный список — как блокнот: можно писать и стирать. Кортеж — как табличка с гравировкой: что написано, то навсегда.

score = (34, 22, 79) print(score[0]) # 34 — прочитать можно # score[0] = 100 # ← а так нельзя, ошибка
🧠 Когда нужен кортеж

Когда данные не должны меняться: например, координаты точки на карте, цвета светофора, дни недели. Кортеж защищает от случайных изменений.

07 Строка в список 🌱🌱🌱
