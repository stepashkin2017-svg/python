⏱ 12–22 минут · 🧠 Оператор if

Команда if: «если — то»

Самое простое: одно условие — одно действие. Если условие верное — действие выполняется. Если нет — просто идём дальше.

Что такое условие

Условие
Это выражение, которое может быть либо истинным (True), либо ложным (False). Python вычисляет его и решает, что делать дальше.
Например: age >= 18, password == 'python', x != 0 — всё это условия.

Операторы сравнения

Вот шесть операторов, из которых чаще всего строятся условия:

ОператорЧто проверяетПример
==равноage == 18
!=не равноx != 0
<меньшеn < 100
>большеn > 0
<=меньше или равноn <= 10
>=больше или равноage >= 18
⚠️ Не путай = и ==

= — это присваивание: «положи в переменную». == — это сравнение: «проверь, равны ли». Очень частая ошибка новичка — написать if x = 5 вместо if x == 5.

Как это записать в Python

if идёт_дождь: взять_зонт()
1Пишем слово if маленькими буквами. Это «если».
2Дальше — условие и двоеточие :.
3С новой строки — действие с отступом в 4 пробела.

Настоящий пример: возраст и права

age = int(input('Сколько тебе лет? ')) if age >= 18: print('Можно водить машину') print('Программа завершена')

Читается так: «Если возраст 18 или больше — напечатай "Можно водить машину"». А строка Программа завершена стоит без отступа — она сработает в любом случае.

🧠 Что заметил

Если условие истинно — строчка с отступом выполняется. Если ложно — Python её пропускает и идёт к следующей строке без отступа.

⏱ 22–32 минут · 🔀 if / else

А если условие не сработало?

В примере с возрастом была проблема: если тебе меньше 18 — программа молчала. Скучно! Хочется, чтобы она отвечала в любом случае.

🤖
Да! Мне нужен второй путь. Если первое условие не подошло — сделай что-то другое. Для этого есть команда else — «иначе».

Как это выглядит на схеме

🎫
Возраст 18 или больше?
🚗
Да → if
«Можно водить»
🧒
Нет → else
«Рано ещё»

Код с else

if age >= 18: print('Можно водить машину') else: print('Рано ещё')
else
Это «иначе». Срабатывает всегда, когда условие в if оказалось ложным. Своё условие у else писать не нужно — только двоеточие и тело с отступом.
Между if и else не может быть никаких строк — они образуют единую конструкцию.

Да (True)
↓
Можно водить
Нет (False)
↓
Рано ещё

Теперь с else!Программа ответит в любом случае

🧠 Классика жанра

Конструкция if / else — это классический условный оператор. Он есть во всех языках, только пишется чуть по-разному. Дальше мы узнаем, что бывает вложенный вариант (одна конструкция внутри другой) и многоветвевой (if / elif / else).

⏱ 40–45 минут · 📬 Ошибки и домашка

Три самые частые ошибки

Разберём ошибки, на которых спотыкаются все новички.

❌Ошибка 1. Забыл двоеточие

После if и else обязательно ставится двоеточие.

if x > 10
    print('больше')

Что скажет Python:

SyntaxError: expected ':'

Как исправить:

if x > 10:
    print('больше')
❌Ошибка 2. Забыл отступ в теле условия

Действия внутри if и else пишутся с отступом в 4 пробела.

if x > 10:
print('больше')

Что скажет Python:

IndentationError: expected an indented block

Как исправить:

if x > 10:
    print('больше')
❌Ошибка 3. Спутал = и ==

= — присваивание, == — сравнение.

if x = 5:        # ← ошибка
    print('пять')

Как исправить:

if x == 5:
    print('пять')
