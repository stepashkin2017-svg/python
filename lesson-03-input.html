Команда input — Пик задаёт вопрос

Один инструмент — одна идея. Пять минут объяснения — и сразу к практике.

Проблема

Пик не умеет слушать. Он может только сам говорить. Если кто-то садится за компьютер — Пик не спросит имя, не узнает, из какого человек города, не поинтересуется его любимой игрой.

Идея

У Python есть команда input() — она задаёт вопрос и ждёт ответа. Пользователь пишет что-то и нажимает Enter — то, что он написал, попадает в переменную.

input()
Команда, которая спрашивает у пользователя данные. В скобках — что именно спросить (текст подсказки). Ответ всегда попадает в переменную.
name = input('Как тебя зовут? ')
Пик спрашивает, пользователь вводит имя — оно сохраняется в переменную name.

Синтаксис — как устроена команда

name = input('Как тебя зовут? ')
1 name — переменная, куда попадёт ответ.
2 = — присваивание. Ответ кладём в переменную.
3 input('...') — команда «спроси». В кавычках — текст подсказки, который увидит пользователь.
⚠️ Пробел в конце подсказки

Обрати внимание: перед закрывающей кавычкой стоит пробел: 'Как тебя зовут? '. Без него пользователь увидит Как тебя зовут?Аня — слипшийся ответ.

Простое правило: в конце подсказки input() всегда ставь пробел.

Маленький секрет: input возвращает строку

Здесь кроется самая частая ошибка новичков. Команда input() всегда возвращает текст (тип str), даже если пользователь ввёл число.

age = input('Сколько тебе лет? ') print(age + 1) # ← ошибка! текст + число нельзя
Что скажет Python
Сколько тебе лет? 12
TypeError: can only concatenate str (not "int") to str
🚨 Почему так

Python не умеет складывать текст и число. '12' — это строка из двух символов, а 1 — число. Программа честно говорит: «не понимаю, что ты хочешь».

Преобразование: int() и float()

Решение — превратить строку в число. Для этого есть две команды.

int()
Превращает строку в целое число.
int('12') → 12
int('100') → 100
float()
Превращает строку в дробное число.
float('3.14') → 3.14
float('1.75') → 1.75

Как выглядит правильный код:

age = int(input('Сколько тебе лет? ')) print('Через год тебе будет', age + 1)
Что выведет программа
Сколько тебе лет? 12
Через год тебе будет 13

Читаем изнутри наружу

Строка int(input('...')) состоит из трёх действий. Выполняются они изнутри наружу:

1 input('...') — спросить и получить строку.
2 int(...) — превратить её в число.
3 age = ... — положить результат в переменную.

Пишем программу знакомства

Соберём вместе программу, которая спрашивает у пользователя имя, город и возраст, а потом печатает рассказ.

Шаг 1. Спросим имя

Самое простое — спросить имя. Ответ всегда текст, кавычки не нужны (мы просто записываем ответ в переменную).

name = input('Как тебя зовут? ') print('Привет,', name + '!')
Что выведет программа
Как тебя зовут? Аня
Привет, Аня!

Шаг 2. Спросим возраст — и превратим в число

Возраст — число. Здесь обязательно использовать int(), чтобы потом можно было что-то посчитать.

name = input('Как тебя зовут? ') age = int(input('Сколько тебе лет? ')) print('Привет,', name + '!') print('Через 10 лет тебе будет', age + 10)
Что выведет программа
Как тебя зовут? Аня
Сколько тебе лет? 12
Привет, Аня!
Через 10 лет тебе будет 22
🧠 Без int() не сработало бы

Если бы мы написали age = input(...), в переменной лежала бы строка '12'. И тогда age + 10 выдало бы ошибку. С int() всё работает.

Шаг 3. Спросим рост — а это уже float

Рост может быть дробным, например 1.55 метра. Для дробных чисел используем float().

name = input('Как тебя зовут? ') age = int(input('Сколько тебе лет? ')) height = float(input('Какой у тебя рост? ')) print('Имя:', name) print('Возраст:', age) print('Рост:', height)
Что выведет программа
Как тебя зовут? Аня
Сколько тебе лет? 12
Какой у тебя рост? 1.55
Имя: Аня
Возраст: 12
Рост: 1.55

Три самые частые ошибки и домашнее задание

Прежде чем расходиться, посмотрим на подводные камни команды input(). И получим домашку.

❌ Ошибка 1. Забыл кавычки в подсказке

Подсказка — это текст, значит, должна быть в кавычках.

name = input(Как тебя зовут? )

Что скажет Python:

SyntaxError: invalid syntax

Как исправить:

name = input('Как тебя зовут? ')
❌ Ошибка 2. Забыл int() — считает строки

Это самая коварная ошибка. Python не выдаст ошибку, пока ты не попробуешь посчитать.

age = input('Возраст: ')
print('Через год:', age + 1)

Что скажет Python:

TypeError: can only concatenate str (not "int") to str

Как исправить — добавить int():

age = int(input('Возраст: '))
print('Через год:', age + 1)
❌ Ошибка 3. Пользователь ввёл не число

Если попросить число через int(input(...)), а пользователь введёт текст — программа упадёт.

age = int(input('Возраст: '))
# пользователь вводит: двенадцать

Что скажет Python:

ValueError: invalid literal for int() with base 10: 'двенадцать'

В наших простых программах мы пока это не обрабатываем — просто просим пользователя вводить корректно. Но помни: такая ошибка возможна.
