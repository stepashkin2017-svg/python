⏱ 20–28 минут · 🔁 Игровой цикл

Оживляем игру

Что отличает игру от обычной картинки? Игра работает непрерывно: каждую секунду она проверяет события и заново рисует экран. Это делает игровой цикл.

👩‍💼
Байт, я заметила — окно без цикла закрывается моментально. А ведь оно должно ждать игрока: он нажмёт клавишу, сделает ход. Без игрового цикла игра не работает.
Игровой цикл
Бесконечный цикл, который крутится, пока игра запущена. На каждом круге — одном кадре — он делает одно и то же: проверяет события, обновляет картинку, ждёт немного времени.
Обычно 40–60 кадров в секунду.
🎬
Аналогия: мультфильм

Мультфильм — это много быстрых картинок, которые сменяют друг друга. Каждая картинка — кадр. Игровой цикл как раз и делает эти кадры.

5 pygame.display.update()
Что делает

Показать на экране всё, что мы нарисовали. Без этой команды ничего не появится — всё останется в памяти.

🎭
Аналогия: занавес в театре

Актёры подготовились за кулисами, но пока занавес закрыт, зритель ничего не видит. pygame.display.update() — «открой занавес».

window.fill((200, 200, 255)) pygame.display.update() # ← вот теперь видно
6 clock = pygame.time.Clock()
Что делает

Создаёт игровой таймер. Он будет считать, сколько кадров в секунду делает игра. Создаётся один раз, до цикла.

⏱️
Аналогия

Это секундомер, который следит за скоростью игры. Он помогает ей работать «в одном ритме».

clock = pygame.time.Clock()
7 clock.tick(40)
Что делает

Устанавливает скорость игры — примерно 40 кадров в секунду. Вызывается один раз за кадр, в конце цикла.

🎞️
Аналогия

Мультфильм показывают со скоростью 24 кадра в секунду. tick(40) говорит игре: «делай 40 кадров в секунду».

while running: # ...рисуем... clock.tick(40)
🤖
Теперь соединим всё вместе — получится «скелет» игры, который работает непрерывно и закрывается по крестику.
import pygame pygame.init() window = pygame.display.set_mode((500, 500)) clock = pygame.time.Clock() running = True while running: for event in pygame.event.get(): if event.type == pygame.QUIT: running = False window.fill((200, 200, 255)) pygame.display.update() clock.tick(40)
🧠 Что здесь новое

1. До цикла создаём таймер: clock = ...Clock().
2. Внутри цикла в конце каждого кадра вызываем clock.tick(40).
3. Флажок running = True держит цикл, а событие QUIT (крестик в углу) опускает его.

03 Игровой цикл 🌱🌱

Сделай окно с игровым циклом и таймером 40 кадров в секунду. Окно закрывается крестиком.

💡 Подсказка

Переменная running = True, цикл while running, обработка QUIT, в конце clock.tick(40).

✅ Решение 
import pygame

pygame.init()
window = pygame.display.set_mode((500, 500))
clock = pygame.time.Clock()

running = True
while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False

    window.fill((255, 255, 255))
    pygame.display.update()
    clock.tick(40)
04 Прямоугольник 🌱🌱

Нарисуй прямоугольник Rect(100, 150, 200, 80) фиолетовым цветом.

💡 Подсказка

Создай rect = pygame.Rect(...) до цикла, внутри вызови pygame.draw.rect(...).

✅ Решение 
import pygame

pygame.init()
window = pygame.display.set_mode((500, 500))
clock = pygame.time.Clock()
rect = pygame.Rect(100, 150, 200, 80)

running = True
while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False

    window.fill((255, 255, 255))
    pygame.draw.rect(window, (150, 100, 200), rect)
    pygame.display.update()
    clock.tick(40)

06 Слушаем Q и A 🌱🌱🌱

При нажатии Q печатай в консоль «Нажата Q!», при нажатии A — «Нажата A!».

💡 Подсказка

Внутри цикла проверь event.type == pygame.KEYDOWN и сравни event.key с pygame.K_q и pygame.K_a.

✅ Решение 
import pygame

pygame.init()
window = pygame.display.set_mode((500, 500))
clock = pygame.time.Clock()

running = True
while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False
        if event.type == pygame.KEYDOWN:
            if event.key == pygame.K_q:
                print('Нажата Q!')
            if event.key == pygame.K_a:
                print('Нажата A!')

    window.fill((255, 255, 255))
    pygame.display.update()
    clock.tick(40)
07 Цвет по клавишам 🌱🌱🌱

При нажатии Q — фон красный, A — зелёный, S — синий. Начальный фон — белый.

💡 Подсказка

Переменная back = (255, 255, 255) до цикла. Меняй её при нажатии. Внутри цикла window.fill(back).

✅ Решение 
import pygame

pygame.init()
window = pygame.display.set_mode((500, 500))
clock = pygame.time.Clock()
back = (255, 255, 255)

running = True
while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False
        if event.type == pygame.KEYDOWN:
            if event.key == pygame.K_q:
                back = (255, 0, 0)
            if event.key == pygame.K_a:
                back = (0, 255, 0)
            if event.key == pygame.K_s:
                back = (0, 0, 255)

    window.fill(back)
    pygame.display.update()
    clock.tick(40)
