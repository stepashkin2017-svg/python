Письмо из «Go Ahead!»

Компания «Go Ahead!» снова обратилась к Байту. На этот раз — с просьбой посложнее: нужно сделать программу, которая сама отвечает клиентам спортивного центра.

🤖
Вот, читаю письмо: «У нас в спортивном центре на стойке информации стоит компьютер. Клиенты подходят и пишут разные вопросы. Нужна программа, которая распознаёт вопрос и печатает ответ».

Самые частые вопросы клиентов такие:

Что пишет клиентЧто отвечает программа

«Забыл телефон тренера» Печатает контакты
«Сколько нужно заплатить за занятия?» Считает и печатает сумму
🤖
Я уже придумал, как это сделать. Но подождите… Если я напишу все эти команды прямо в одной программе — она станет огромной. А если завтра другой спортивный центр закажет такую же — мне придётся всё копировать заново!

Как обычно делает Байт

Смотри, вот как выглядел бы код, если написать всё в одном файле:

# main.py — всё в одном файле def print_schedule(): print('Расписание: пн-пт 9:00–21:00') def print_trainer(): print('Тренер: Борисов И.С., +7 (900) 123-45-67') def print_price(): print('Стоимость: 800 руб. за занятие') # ... и ещё много строк основного кода answer = input('Ваш запрос: ') while answer != 'off': if answer == 'расписание': print_schedule() elif answer == 'тренер': print_trainer() elif answer == 'цена': print_price() answer = input('Ваш запрос: ')
⚠️ Что неудобно

1. Файл растёт. Если завтра попросят добавить ещё 10 видов запросов — код превратится в кашу.

2. Нельзя переиспользовать. Другой спортцентр хочет такую же программу — придётся копировать все функции вручную.

3. Смешивается всё подряд: и функции-ответы, и главный цикл, который спрашивает клиента. Хочется разделить.

Есть отличный выход: вынести все функции в отдельный файл. Этот файл называется модуль. О нём и поговорим.

Модуль — это отдельный файл с функциями

Мы уже пользовались чужими модулями — random и time. Оказывается, можно сделать и свой собственный.

Модуль
Это обычный файл с расширением .py, внутри которого лежат функции или другой код. Его можно подключить к другим программам через import и использовать все функции, которые внутри.
Файл analyser.py — модуль с функциями-ответами.
Файл main.py — основная программа, которая его подключает.

Аналогия: ящик с инструментами

Представь, что функции — это инструменты. Раньше Байт носил их все в одном рюкзаке и путался. А можно сложить их в отдельный ящик — и когда нужен молоток, просто открыть ящик и взять.

🧠 Почему это удобно

1. Понятнее. В основном файле — только логика: что спросить и куда передать. Все ответы — в модуле.

2. Переиспользуется. Модуль можно подключить к любой другой программе. Один раз написали — используем везде.

3. Менять легко. Изменил текст ответа в модуле — и это применилось сразу во всех программах, где он подключён.

Пишем файл analyser.py

Чтобы создать свой модуль, нужно сделать всего две вещи: сохранить файл с функциями и подключить его в главной программе.

🤖
Сейчас я мысленно создам новый файл. Назову его analyser.py — «анализатор». Внутри напишу три функции: для расписания, для тренера и для цены.

Первый шаг — сохранить файл

analyser.py — наш модуль
def print_schedule():
    print('Расписание занятий:')
    print('  Пн-Пт: 9:00 — 21:00')
    print('  Сб:    10:00 — 18:00')

def print_trainer():
    print('Главный тренер: Борисов Иван Сергеевич')
    print('Телефон: +7 (900) 123-45-67')

def print_price():
    print('Стоимость одного занятия: 800 руб.')
    print('Абонемент на 10 занятий: 7000 руб.')
🧠 Что внутри модуля

Только определения функций — то есть строки, которые начинаются со слова def. Никаких input() и while внутри нет.

Почему? Потому что модуль — это как ящик с инструментами. Он не работает сам по себе. Кто-то должен его «открыть» и вызвать нужную функцию. Это делает главная программа.

⚠️ Правила создания модуля

1. Имя файла — понятное, латиницей, маленькими буквами, слова через подчёркивание: analyser.py, zoo_info.py, my_math.py.

2. Расширение обязательно .py — иначе Python не поймёт, что это код.

3. Внутри — только функции и определения. Ввод, циклы верхнего уровня и вызовы print() вне функций — не нужны.

4. Файл должен лежать в той же папке, что и главная программа. Иначе Python не найдёт модуль.

Подключаем модуль к программе

Файл-модуль готов. Теперь нужно сделать так, чтобы основная программа «увидела» его и могла вызывать функции из него.

import
Это команда, которая подключает модуль к программе. После этого все функции и переменные модуля становятся доступны.
import analyser — подключить наш модуль.
Дальше функции вызываются так: analyser.print_schedule().

Второй шаг — подключить модуль в главной программе

main.py — основная программа
import analyser

print('Добро пожаловать в спортцентр!')

answer = input('Ваш запрос (off — выход): ')

while answer != 'off':
    if answer == 'расписание':
        analyser.print_schedule()
    elif answer == 'тренер':
        analyser.print_trainer()
    elif answer == 'цена':
        analyser.print_price()
    else:
        print('Извините, я вас не понял.')

    answer = input('Ваш запрос (off — выход): ')

print('Хорошей тренировки!')

Как это работает

1 Строка import analyser — Python «открывает» файл analyser.py и запоминает все функции внутри.
2 Когда мы пишем analyser.print_schedule() — Python ищет функцию print_schedule в модуле analyser и выполняет её.
3 Через точку после имени модуля мы указываем, какую именно функцию хотим вызвать. Так видно, откуда она «пришла».

Три способа подключения модуля

Модуль можно подключить по-разному. Все три способа рабочие, но у каждого свои особенности.

ЗаписьКак вызывать функцию
import analyser analyser.print_schedule()
from analyser import print_schedule print_schedule()
from analyser import * print_schedule()
🧠 Какой способ выбрать

Для учебных программ удобно писать import analyser — всегда видно, откуда пришла функция, и легко искать её в файлах.

Второй способ короче, но если функций в модуле много — придётся перечислять их через запятую: длинно и неудобно.

Третий способ (import *) самый короткий, но считается плохим тоном: непонятно, откуда какая функция взялась. Лучше не использовать.

main.py
import analyser

print('Спортивный центр «Go Ahead!». Чем помочь?')

while answer != 'off':

        analyser.print_schedule()
    elif answer == 'тренер':
        analyser.print_trainer()
    elif answer == 'цена':
        analyser.print_price()

        print('Извините, я вас не понял.')

Что делает программа:
1. Подключает модуль analyser.
2. Печатает приветствие и спрашивает запрос.
3. В цикле while проверяет, что ввёл клиент, и вызывает нужную функцию из модуля.
4. Если запрос неизвестный — печатает «Извините, я вас не понял.»
5. По слову off — завершает работу.

2. В основной программе добавить ветку elif answer == 'бассейн': analyser.print_pool().

Всё! Остальные части программы не меняются. Именно в этом прелесть модулей: добавили одну функцию — и всё работает.

04 Модуль-калькулятор 🌱🌱

Модуль my_math.py с функциями add(a, b) и multiply(a, b). Каждая возвращает результат.

💡 Подсказка

Функции возвращают результат через return. В главной программе — print(my_math.add(2, 3)).

✅ Решение 
# my_math.py
def add(a, b):
    return a + b

def multiply(a, b):
    return a * b

# main.py
import my_math
print(my_math.add(2, 3))
print(my_math.multiply(4, 5))
05 Автоответчик 🌱🌱🌱

Модуль answers.py с функциями schedule(), coach(), price(). Главная программа спрашивает пользователя и вызывает нужную функцию.

💡 Подсказка

В главной программе: import answers, цикл while, цепочка if/elif/else.

✅ Решение 
# answers.py
def schedule():
    print("Расписание: пн-пт с 9:00 до 21:00.")

def coach():
    print("Телефон тренера: +7 (900) 123-45-67.")

def price():
    print("Одно занятие — 800 рублей.")

# main.py
import answers

answer = input("Запрос (расписание / тренер / цена, off — выход): ")
while answer != "off":
    if answer == "расписание":
        answers.schedule()
    elif answer == "тренер":
        answers.coach()
    elif answer == "цена":
        answers.price()
    else:
        print("Не понимаю запрос.")
    answer = input("Запрос (расписание / тренер / цена, off — выход): ")

# info.py
def winter():

import info

07 Свой модуль 🌱🌱🌱

Придумай свой модуль на 3–4 функции. Например, recipes.py с рецептами блюд или games.py с правилами игр.

💡 Подсказка

Имя модуля — понятное. Внутри — только функции, без input() и циклов.

✅ Решение 
# recipes.py
def pancakes():
    print("Блины: мука, молоко, яйца, сахар.")

def soup():
    print("Суп: вода, картофель, морковь, лук.")

def salad():
    print("Салат: помидоры, огурцы, зелень, масло.")

# main.py
import recipes
print("Сегодня в меню:")
recipes.pancakes()
recipes.soup()
recipes.salad()
