⏱ 5–12 минут · 🖱️ Координаты мыши

Команда 1: где сейчас мышка?

Чтобы понять, куда игрок попал, надо сначала научиться узнавать координаты. Есть специальная команда.

1 pygame.mouse.get_pos()
Что делает

Возвращает координаты мыши в виде пары чисел (x, y). Отсчёт — от левого верхнего угла окна.

📖
Аналогия. Это как спросить у системы: «а где сейчас курсор?». Ответ будет у любой игры с мышью — неважно, нажал игрок или нет.
Как пишется
import pygame pygame.init() window = pygame.display.set_mode((600, 500)) # узнать, где сейчас мышь mouse_pos = pygame.mouse.get_pos() print(mouse_pos) # например: (300, 250)
Куда указывает?

(0, 0) — левый верхний угол окна. Координаты всегда положительные и растут вправо и вниз.

Посмотрим на живом примере

Води мышкой над этой областью — увидишь координаты.

Наведи мышку сюда
(—, —)
pygame.mouse.get_pos()
🧠 Важно про систему координат

В Pygame отсчёт не от центра, а от левого верхнего угла. Значит, все координаты положительные. Если окно 600×500, то максимальная точка — (600, 500).

⏱ 12–22 минут · ⚠️ Важный выбор

Почему нельзя считать клики через get_pressed?

Есть соблазн использовать get_pressed() — команда из урока 27, которая возвращает True/False. Но в тире она даёт баг. Разберёмся, почему.

Первая попытка: get_pressed()

import pygame from random import randint pygame.init() window = pygame.display.set_mode((600, 500)) clock = pygame.time.Clock() target_x = randint(100, 500) target_y = randint(100, 400) target_r = 40 score = 0 running = True while running: for event in pygame.event.get(): if event.type == pygame.QUIT: running = False # ⚠️ вот тут ошибка: left, _, _ = pygame.mouse.get_pressed() mx, my = pygame.mouse.get_pos() dx = mx - target_x dy = my - target_y if left and dx * dx + dy * dy <= target_r * target_r: score += 1 window.fill((255, 255, 255)) pygame.draw.circle(window, (229, 57, 53), (target_x, target_y), target_r) pygame.display.update() clock.tick(40) pygame.quit()
🚨 Что случится

Пока игрок держит левую кнопку мыши, left остаётся True на каждом кадре. А цикл бежит 40 раз в секунду. Значит, за секунду удержания счёт вырастет на 40!

Как будто выстрел в тире срабатывает не один раз, а пока палец на курке.

Проверь сам — зажми мишень

Правильный способ: событие MOUSEBUTTONDOWN

2 pygame.MOUSEBUTTONDOWN
Что делает

Событие, которое приходит один раз при нажатии кнопки мыши. У события есть два полезных поля:

event.button — какая кнопка: 1 — левая, 2 — средняя, 3 — правая.
event.pos — координаты (x, y), где произошёл клик.

🔔
Аналогия. get_pressed() — как «горит ли лампочка». MOUSEBUTTONDOWN — как звонок. Он звенит один раз и замолкает. Нам нужен именно звонок.
Как пишется
for event in pygame.event.get(): if event.type == pygame.MOUSEBUTTONDOWN: if event.button == 1: print('Клик в точке:', event.pos)

Сравнение двух подходов

❌ get_pressed()
left, _, _ = pygame.mouse.get_pressed()
if left and dx*dx + dy*dy <= r*r:
    score += 1
Проблема: left держится True на каждом кадре. Удержание = +40 очков за секунду.
✅ MOUSEBUTTONDOWN
for event in pygame.event.get():
    if event.type == pygame.MOUSEBUTTONDOWN:
        if target.is_hit(event.pos):
            score += 1
Плюс: событие приходит один раз. Один клик — одно очко. Даже если держать мышь — счёт не растёт.

Проверь: теперь правильно

Зажми мишень — счёт увеличится ровно на 1.

Очки: 0
# событие клика # один клик — одно очко
⚠️ Правило из игр

Событие — что-то, что произошло один раз (клик, нажатие клавиши, закрытие окна). Обрабатывается через pygame.event.get().

Состояние — то, что происходит прямо сейчас (кнопка мыши зажата, клавиша удерживается). Читается через get_pressed() или key.get_pressed().

Клик — это событие. Удержание — состояние.

⏱ 22–32 минут · 📦 Класс Target

Упаковываем мишень в класс

Мы знаем классы — урок 24. Мишень — идеальный кандидат: у неё есть свойства (координаты, радиус) и методы (проверить попадание, нарисовать, перепрыгнуть).

🧠 Зачем класс?

Без класса пришлось бы держать отдельные переменные: target_x, target_y, target_r… И для каждой новой мишени — свой набор.

Класс собирает всё это в один «ящик». И рядом кладёт методы, которые работают с этими данными.

Класс Target

class Target(): def __init__(self, x, y, radius): self.x = x self.y = y self.radius = radius def is_hit(self, pos): # проверяем: попал ли клик в мишень? mx, my = pos dx = mx - self.x dy = my - self.y return dx * dx + dy * dy <= self.radius * self.radius def move_random(self): # прыгнуть в случайное место self.x = randint(80, 520) self.y = randint(80, 420) def draw(self, surface): pygame.draw.circle(surface, (229, 57, 53), (self.x, self.y), self.radius)

🧠 Разбор методов

1. __init__ — конструктор. Запоминает координаты и радиус.

2. is_hit(pos) — принимает координаты клика и проверяет: попал ли он в круг? Внутри — та же формула расстояния: dx² + dy² ≤ r².

3. move_random() — переставляет мишень в случайное место через randint.

4. draw(surface) — рисует мишень на указанной поверхности.

Используем класс

import pygame from random import randint pygame.init() window = pygame.display.set_mode((600, 500)) clock = pygame.time.Clock() # создаём мишень в центре target = Target(300, 250, 40) score = 0 font1 = pygame.font.Font(None, 40) running = True while running: for event in pygame.event.get(): if event.type == pygame.QUIT: running = False # ← проверяем попадание if event.type == pygame.MOUSEBUTTONDOWN: if target.is_hit(event.pos): score += 1 target.move_random() window.fill((255, 255, 255)) target.draw(window) text = font1.render('Очки: ' + str(score), True, (0, 0, 0)) window.blit(text, (20, 20)) pygame.display.update() clock.tick(40) pygame.quit()

⚠️ Почему move_random после попадания

Если мишень останется на старом месте, игрок может просто держать кнопку и кликать в одну точку. Перескакивание мишени заставляет каждый раз целиться заново — и это интереснее.

Финальный код тира

Вот полная программа. Разберём по частям, чтобы ты мог написать свою версию.

🧠 Разбор по шагам

1. Объявляем класс Target.
2. Создаём мишень и счёт до игрового цикла.
3. В цикле событий ловим MOUSEBUTTONDOWN.
4. Если клик попал в мишень — +1 к счёту и перепрыгнуть.
5. Рисуем мишень и счёт. Обновляем экран.

Что здесь важного
Один клик = одно очко. Событие MOUSEBUTTONDOWN приходит один раз. Удержание не помогает.
Хочешь три мишени? Просто создай список из трёх Target и обходи его в цикле. Но это уже другая задача — попробуем в заданиях.

03 Попадание в круг 🌱🌱

Нарисуй круг с центром (300, 250) и радиусом 60. Печатай «Попал!», если клик попал в круг.

💡 Подсказка

Проверь расстояние: dx*dx + dy*dy <= r*r.

✅ Решение 
import pygame

pygame.init()
window = pygame.display.set_mode((600, 500))
clock = pygame.time.Clock()

target_x, target_y, target_r = 300, 250, 60

running = True
while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False
        if event.type == pygame.MOUSEBUTTONDOWN:
            mx, my = event.pos
            dx = mx - target_x
            dy = my - target_y
            if dx * dx + dy * dy <= target_r * target_r:
                print('Попал!')

    window.fill((240, 245, 250))
    pygame.draw.circle(window, (229, 57, 53),
                       (target_x, target_y), target_r)
    pygame.display.update()
    clock.tick(40)

pygame.quit()

06 Класс Target 🌱🌱🌱

Упакуй мишень в класс Target с методами is_hit(pos) и draw(surface). Используй его в основной программе.

💡 Подсказка

В конструкторе сохрани x, y, radius. Метод is_hit — та же формула расстояния.

✅ Решение 
import pygame
from random import randint

pygame.init()
window = pygame.display.set_mode((600, 500))
clock = pygame.time.Clock()
font1 = pygame.font.Font(None, 40)

class Target():
    def __init__(self, x, y, radius):
        self.x = x
        self.y = y
        self.radius = radius

    def is_hit(self, pos):
        mx, my = pos
        dx = mx - self.x
        dy = my - self.y
        return dx * dx + dy * dy <= self.radius * self.radius

    def move_random(self):
        self.x = randint(80, 520)
        self.y = randint(80, 420)

    def draw(self, surface):
        pygame.draw.circle(surface, (229, 57, 53),
                           (self.x, self.y), self.radius)

07 Мишень с кольцами 🌱🌱🌱

Сделай так, чтобы мишень выглядела как настоящая: красный круг, белое кольцо, красный центр.

💡 Подсказка

Три draw.circle подряд: радиус r, r//2, r//4. Цвета — красный, белый, красный.

✅ Решение 
import pygame
from random import randint

pygame.init()
window = pygame.display.set_mode((600, 500))
clock = pygame.time.Clock()
font1 = pygame.font.Font(None, 40)

class Target():
    def __init__(self, x, y, radius):
        self.x = x
        self.y = y
        self.radius = radius

    def is_hit(self, pos):
        mx, my = pos
        dx = mx - self.x
        dy = my - self.y
        return dx * dx + dy * dy <= self.radius * self.radius

    def move_random(self):
        self.x = randint(80, 520)
        self.y = randint(80, 420)

    def draw(self, surface):
        r = self.radius
        pygame.draw.circle(surface, (229, 57, 53), (self.x, self.y), r)
        pygame.draw.circle(surface, (255, 255, 255), (self.x, self.y), r // 2)
        pygame.draw.circle(surface, (229, 57, 53), (self.x, self.y), r // 4)

target = Target(300, 250, 60)
score = 0

running = True
while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False
        if event.type == pygame.MOUSEBUTTONDOWN:
            if target.is_hit(event.pos):
                score += 1
                target.move_random()

    target.draw(window)
