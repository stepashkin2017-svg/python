Переменная — коробка с наклейкой

Один инструмент. Одна идея. Пять минут объяснения — и сразу к практике.

Проблема

Пик вынужден писать своё имя в каждой команде заново. Если мы поменяем имя — придётся править все строки. Это неудобно и легко ошибиться.

Идея

Как в жизни: мы же не пишем своё имя заново в каждом документе — мы просто кладём паспорт в ящик и достаём его, когда нужно. Точно так же и в программе: кладём значение в коробку с наклейкой, а потом просто достаём по наклейке.

Переменная
Это коробка с наклейкой, в которой программа хранит одно значение. Наклейка — это имя переменной. Внутри — значение.
name = 'Пик'
Коробка с наклейкой name. Внутри — текст 'Пик'.
'Пик'
тип: str
1
тип: int
0.5
тип: float
True
тип: bool

Синтаксис — создание переменной

name = 'Пик'
1 name — имя переменной (наклейка на коробке). Придумываем сами.
2 = — знак присваивания. Не «равно», а «положи справа в коробку слева».
3 'Пик' — значение. Текст в кавычках, числа без.

Четыре типа данных

У каждой коробки есть свой тип — что именно в ней лежит. Четыре самых главных:

ТипЧто хранитПример
int Целое число age = 1
float Дробное число height = 0.5
str Строка (текст) name = 'Пик'
bool Истина или ложь is_awake = True
⚠️ Ключевое правило

Текст (тип str) — всегда в кавычках.
Числа (int и float) — без кавычек.
Логические значения пишутся с большой буквы: True, False.

Как использовать переменную

Когда переменная создана, её имя можно писать где угодно вместо значения. Python подставит то, что лежит в коробке.

name = 'Пик' print('Меня зовут', name) print('Привет от', name) print(name, 'учится программировать')
Что выведет программа
Меня зовут Пик
Привет от Пик
Пик учится программировать
🧠 Сила переменной

Теперь, если мы захотим сменить имя, поменяем только одну строку — там, где создана переменная. Все print, которые её используют, сразу покажут новое значение.

Это и есть главная идея переменных: написал один раз — используй везде.

Создаём переменные Пика

Откроем Playground и сделаем Пику целый набор переменных. Разберём все четыре типа.

Шаг 1. Имя — это текст (str)

Сначала — самое главное. Создаём переменную с именем Пика. Значение — текст, значит в кавычках.

name = 'Пик' print('Привет, я', name)
Что выведет программа
Привет, я Пик

Шаг 2. Возраст — целое число (int)

Пику ровно 1 день от рождения. Это целое число — пишем без кавычек.

name = 'Пик' age = 1 print('Меня зовут', name, 'мне', age, 'день')
Что выведет программа
Меня зовут Пик мне 1 день

Шаг 3. Рост — дробное число (float)

Пик очень маленький — его рост 0.5 условных пикселя. Дробное число, пишем через точку (не запятую!).

name = 'Пик' age = 1 height = 0.5 print('Мой рост:', height)
Что выведет программа
Мой рост: 0.5
⚠️ Точка, не запятая

В Python дробные числа пишутся через точку: 0.5, 1.75, 3.14. Запятая — это уже другой символ, так писать нельзя.

Шаг 4. Пик проснулся? — логический тип (bool)

Есть ещё один тип — «истина или ложь». Пик только что проснулся, значит — True.

name = 'Пик' age = 1 height = 0.5 is_awake = True print('Пик проснулся:', is_awake)
Что выведет программа
Пик проснулся: True
🧠 Что такое True и False

Логический тип хранит ответ на вопрос «да или нет». True — истина, False — ложь. Пишутся с большой буквы.

Этот тип пригодится, когда мы будем учить программу принимать решения — например, «Пик спит? — Нет, значит, идём гулять».

Все четыре типа вместе

# Все переменные Пика name = 'Пик' # str — текст age = 1 # int — целое height = 0.5 # float — дробное is_awake = True # bool — истина/ложь print('Имя:', name) print('Возраст:', age) print('Рост:', height) print('Проснулся?', is_awake)
Что выведет программа
Имя: Пик
Возраст: 1
Рост: 0.5
Проснулся? True

Три самые частые ошибки и домашнее задание

Прежде чем расходиться, посмотрим, на чём спотыкаются новички с переменными. И получим маленькую домашку.

❌ Ошибка 1. Забыл кавычки у текста

Текст (тип str) всегда в кавычках. Без них Python подумает, что это имя переменной.

name = Пик

Что скажет Python:

NameError: name 'Пик' is not defined

Как исправить — добавить кавычки:

name = 'Пик'
❌ Ошибка 2. Число в кавычках

Числа пишутся без кавычек. Иначе они станут текстом.

age = '1'

Формально ошибки не будет — код запустится. Но age теперь не число, а строка. С ней нельзя считать.

Как правильно — без кавычек:

age = 1
❌ Ошибка 3. Дробное число через запятую

Дробные числа в Python пишутся через точку, а не через запятую.

height = 1,75

Что скажет Python: запятая создаёт кортеж — это уже не одно число, а целая структура. Для новичка — неожиданность.

Как правильно — через точку:

height = 1.75
💡 Как быстро понять, что не так

Спроси себя три вопроса:

1. Что лежит в переменной — текст или число?
2. Если текст — есть ли кавычки?
3. Если число — нет ли лишних кавычек или запятых?

Эти три вопроса решают 90% ошибок с переменными.
