Студия хочет ещё одну игру

Директор Press and Play посмотрел на прототип «Черепашьих гонок» и сказал: «Отличная работа! Но хочется чего-то более интерактивного. Хочу, чтобы игрок сам участвовал».

🤖
Заказ: игра «Поймай черепашку». Черепашка прыгает по экрану, а игрок должен по ней кликнуть мышкой. Если успел — плюс одно очко. Нужно набрать 3 клика — и ты победил! А ещё хотят второй прототип: три черепашки разбегаются в стороны, а ты кликом меняешь их направление, чтобы они не убежали.

Что здесь нового?

Раньше наши программы делали всё по порядку: сверху вниз. Мы не знали, что делает игрок — программа просто бежала свой алгоритм.

Теперь — иначе. Программа не может «угадать», когда игрок кликнет мышкой. Она должна реагировать, когда что-то происходит. Такие «происшествия» называются событиями.

⏱ 5–13 минут · 🎯 Что такое событие

Событие — это то, что произошло

На самом деле ты знаком с событиями очень давно. Это не какая-то программистская магия, а самая обычная жизнь. Давай разберём на примерах.

Это что-то, что произошло во внешнем мире, и о чём компьютер может узнать. Чаще всего это действия пользователя: клик мышкой, нажатие клавиши, движение мыши.
Ты кликнул по черепашке — это событие. Ты нажал «Пробел» — это тоже событие.
🧠 Что значит «внешний мир»?

Для программы «внешний мир» — это всё, что вокруг неё: мышка, клавиатура, тачпад, экран. Программа сама не знает, когда ты кликнешь. Но если ты кликнешь — система (Windows, macOS или платформа) сообщит программе: «Эй, тут событие!».

Программа как будто спит. А когда что-то происходит — просыпается и реагирует.

Как программа узнаёт про событие?

Представь, что ты ждёшь курьера. Ты же не бегаешь каждые 10 секунд к двери с проверкой: «Пришёл? Нет? А теперь? А теперь?». Это было бы очень глупо и утомительно.

Точно так же и программа не проверяет постоянно, кликнул ли ты мышкой. Вместо этого она подписывается на событие и ждёт — пока система сама не сообщит: «Клик!».

💡 Три слова, которые надо знать

1. Событие — что-то случилось (клик мышкой).
2. Подписка — программа говорит: «Я жду это событие».
3. Обработчик — что программа делает, когда событие пришло.

⏱ 13–22 минут · 🔗 Подписка и обработчик

Как подписаться на событие

Разберём, как это работает в коде. На самом деле — очень просто: три коротких строчки.

Разбор на примере дверного звонка

Событие Гость нажал кнопку звонка
→
Система «Дзинь! У квартиры событие»
→
Обработчик Ты открываешь дверь

Точно так же и с программой. Только вместо звонка — клик по черепашке, а вместо тебя — функция-обработчик.

Подписка на событие

Подписка делается одним вызовом метода:

t.onclick(catch) # t — имя черепашки # onclick — «при клике» # catch — имя функции-обработчика

Читается так: «Черепашка t, слушай: когда по тебе кликнут, вызывай функцию catch».

Обработчик события

Обработчик — это функция, которая сработает при событии. У неё должно быть два параметра: координаты клика. Система сама передаст их.

def catch(x, y): # x, y — координаты того места, где кликнули print('Поймали!') print('Клик был в точке:', x, y)
🧠 Куда девать x и y?

Система всегда передаёт координаты клика. Даже если они не нужны — параметры всё равно должны быть в скобках.

Мы их получим, но можем просто не использовать внутри. Например: def catch(x, y): print('Поймали!').

Простейший пример — целиком

Программа: черепашка стоит на месте. Кликаем по ней — в консоли печатается сообщение.

from turtle import * t = Turtle() t.shape('turtle') def catch(x, y): print('Попался!') t.onclick(catch) exitonclick()

Запусти и кликни по черепашке — в консоли появится «Попался!».

Симулятор: подписка на клик

Вот черепашка. Кликни по ней — счётчик кликов вырастет. Это и есть «событие → обработчик» в действии.

В этом симуляторе работает та же логика: 1. Ты кликнул по черепашке (событие).
2. Сработал обработчик — счётчик увеличился.
3. Черепашка сделала вид, что её поймали (подпрыгнула).

Ещё одна команда — write()

В игре нужно показывать надписи — «А!» при клике, «WOW!» при победе. Для этого у черепашки есть метод write():

t.write('А!', font=('Arial', 14, 'normal'))

Шрифт задаётся тремя частями в скобках: название, размер и стиль. Как в текстовом редакторе!

⏱ 22–33 минут · 🐢 Прототип 1

«Поймай черепашку» — первая версия

Теперь соберём всё вместе. Черепашка прыгает по экрану в случайные места. Игрок кликает по ней. Нужно 3 попадания — и победа!

🤖
Есть одна сложность. Нужно посчитать клики и закончить игру после третьего. Обычная переменная тут не сработает: обработчик catch(x, y) должен иметь ровно два параметра — x и y. Третьим мы счётчик не передадим!

Как решить проблему со счётчиком?

Хитрость: сделаем счётчик свойством объекта! У черепашки уже есть свойства: цвет, координаты, форма. А можно добавить ещё одно — например, t.points.

Своё свойство объекта
В Python можно добавить объекту новое свойство — так же просто, как обычной переменной.
t.points = 0 — создали свойство «очки» и сразу поставили в 0.
Теперь внутри функции-обработчика можно писать t.points += 1 — и это сработает, потому что t.points живёт вместе с объектом.

Полная программа

from turtle import * from time import sleep from random import randint t = Turtle() t.color('red') t.shape('turtle') t.penup() t.speed(10) t.points = 0 # ← создаём своё свойство w = 200 h = 200 def rand_move(): x = randint(-w, w) y = randint(-h, h) t.goto(x, y) def catch(x, y): t.write('А!', font=('Arial', 14, 'normal')) t.points += 1 # ← увеличиваем счётчик rand_move() t.onclick(catch) while t.points < 3: # ← играем, пока меньше 3 очков sleep(1.5) rand_move() t.write('WOW!', font=('Arial', 40, 'bold')) exitonclick()

Разбор по шагам

1 Создаём черепашку и сразу добавляем ей своё свойство t.points = 0. Пока очков — ноль.
2 Пишем rand_move() — функция ставит черепашку в случайное место.
3 Пишем обработчик catch(x, y) — что делать при клике: написать «А!», добавить очко, переместить.
4 Подписываемся: t.onclick(catch).
5 Главный цикл: пока очков меньше 3 — пауза 1,5 сек и снова в случайное место. Прыгает!
6 Победа — выводим «WOW!».
🧠 Как работает эта хитрость

Обычная переменная points, созданная снаружи, не изменилась бы внутри функции — Python посчитал бы, что мы создаём новую локальную переменную (помнишь урок 12?).

А t.points — это свойство объекта. Объект один и тот же и снаружи, и внутри функции. Значит, изменение свойства видно везде.

⏱ 33–42 минут · 🐢🐢🐢 Прототип 2

Три черепашки — второй прототип

Второй заказ посложнее: три черепашки одновременно разбегаются в разные стороны. Кликом по каждой меняем её направление. Задача — не дать им убежать за границу экрана.

🤖
Тут есть три события — клик по первой, клик по второй, клик по третьей. У каждой черепашки — свой обработчик. И ещё: нужно определить, когда игра закончится. А для этого проверять — не вышла ли какая-то черепашка за границу.

Что нового понадобится

КомандаЧто делает
t.ycor() Возвращает координату Y черепашки
abs(n) Убирает знак числа: abs(-5) = 5
t.width(n) Делает линию толще на n пикселей
🧠 Зачем нужен abs()

Черепашка может убежать влево (−200) или вправо (+200). И вверх, и вниз. Мы хотим проверить: «далеко ли она от центра?» — не важно, в какую сторону.

abs(t.xcor()) > 200 — читается «расстояние по горизонтали больше 200». Работает и для +200, и для −200.

Функция проверки окончания игры

Опишем функцию, которая возвращает True, если хоть одна черепашка за экраном:

def game_finished(): t1_out = abs(t1.xcor()) > w or abs(t1.ycor()) > h t2_out = abs(t2.xcor()) > w or abs(t2.ycor()) > h t3_out = abs(t3.xcor()) > w or abs(t3.ycor()) > h return t1_out or t2_out or t3_out

Функция возвращает True, если хотя бы одна вышла за границу. Главный цикл использует её как условие.

Обработчики клика для каждой черепашки

Каждая черепашка получит свою функцию-обработчик. При клике она поворачивается в случайную сторону и перепрыгивает в новое место:

def catch1(x, y): t1.penup() t1.goto(randint(-100, 100), randint(-100, 100)) t1.pendown() t1.left(randint(0, 100)) # Аналогично — catch2() и catch3() t1.onclick(catch1) t2.onclick(catch2) t3.onclick(catch3)
🧠 Каждая — на своё событие

У нас три независимых события: «клик по t1», «клик по t2», «клик по t3». Каждое подписывается на свою функцию.

Если кликнуть по t1 — сработает только catch1. Если по t2 — только catch2. Так и должно быть!

Главный игровой цикл

while not game_finished(): t1.forward(7) t2.forward(7) t3.forward(7) sleep(0.1) exitonclick()

Все три черепашки двигаются одновременно, но каждая — в своём направлении. Игрок кликает по ним, чтобы повернуть.

05 Полная игра на 3 очка 🌱🌱🌱

Собери игру «Поймай черепашку»: 3 клика — победа с надписью «WOW!».

💡 Подсказка

После победы выведи t.write('WOW!', font=('Arial', 40, 'bold')).

✅ Решение 
from turtle import *
from time import sleep
from random import randint

t = Turtle()
t.color('red')
t.shape('turtle')
t.penup()
t.points = 0

w = h = 200

def rand_move():
    t.goto(randint(-w, w), randint(-h, h))

def catch(x, y):
    t.write('А!', font=('Arial', 14, 'normal'))
    t.points += 1
    rand_move()

t.onclick(catch)

while t.points < 3:
    sleep(1.5)
    rand_move()

t.write('WOW!', font=('Arial', 40, 'bold'))
exitonclick()
06 Две черепашки — два клика 🌱🌱🌱

Создай двух черепашек. Клик по красной меняет её цвет на зелёный, клик по синей — на жёлтый.

💡 Подсказка

Каждой черепашке — своя функция catch_red, catch_blue. Смотри урок 21, если забыл, как работать с несколькими.

✅ Решение 
from turtle import *

t1 = Turtle()
t1.color('red')
t1.shape('turtle')
t1.penup()
t1.goto(-100, 0)

t2 = Turtle()
t2.color('blue')
t2.shape('turtle')
t2.penup()
t2.goto(100, 0)

def catch_red(x, y):
    t1.color('green')

def catch_blue(x, y):
    t2.color('yellow')

t1.onclick(catch_red)
t2.onclick(catch_blue)
exitonclick()
07 Проверка координат 🌱🌱🌱

При клике по черепашке печатай, на каком расстоянии от центра она находится. Используй abs() и xcor(), ycor().

💡 Подсказка

abs(t.xcor()) и abs(t.ycor()) дают расстояние по осям.

✅ Решение 
from turtle import *

t = Turtle()
t.shape('turtle')

def catch(x, y):

exitonclick()
