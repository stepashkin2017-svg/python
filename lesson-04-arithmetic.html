Семь операторов Python

В Python, как и в математике, есть знаки операций. Но их не пять, как в школе, а семь. Разберём каждый за минуту.

Проблема

Мы умеем спрашивать числа и превращать их в int. Но что с ними делать дальше? Как сложить, умножить, найти остаток?

Идея

У Python есть операторы — знаки, которые ставятся между двумя числами и выполняют над ними действие. Точно так же, как на калькуляторе.

+
Сложение
5 + 3 = 8
−
Вычитание
10 − 4 = 6
*
Умножение
3 * 4 = 12
/
Деление
8 / 2 = 4.0
//
Целое деление
7 // 2 = 3
%
Остаток от деления
7 % 2 = 1
**
Возведение в степень
2 ** 3 = 8

Обычные операции — как в школе

Первые четыре знака + − * / работают ровно так, как ты привык. Просто умножение записывается звёздочкой, а не крестиком.

print(5 + 3) # 8 print(10 - 4) # 6 print(3 * 4) # 12 print(8 / 2) # 4.0
⚠️ Почему 8 / 2 даёт 4.0, а не 4?

Оператор / в Python всегда возвращает дробное число (float), даже если результат целый. Так устроен язык.

Если хочешь получить именно целое — используй //.

Три «необычных» оператора

Их нет в школе, но они очень полезны — особенно в программировании.

Целое деление: //

Возвращает, сколько целых раз одно число делится на другое. Отбрасывает остаток.

print(7 // 2) # 3 (не 3.5) print(10 // 3) # 3 print(100 // 10) # 10

Остаток: %

Возвращает то, что осталось после целочисленного деления.

print(7 % 2) # 1 (7 = 3*2 + 1) print(10 % 3) # 1 (10 = 3*3 + 1) print(10 % 5) # 0 (10 = 2*5 + 0)
🧠 Где пригодится %

Оператор % часто используется, чтобы узнать, чётное ли число: если n % 2 == 0 — чётное. Или чтобы переводить минуты в часы: остаток от деления на 60 — это минуты сверх полных часов.

Степень: **

Возводит число в степень. Два знака умножения.

print(2 ** 3) # 8 (2*2*2) print(5 ** 2) # 25 print(10 ** 3) # 1000

Порядок действий — как в математике

Если в строке несколько операторов, Python выполняет их в определённом порядке. Точно как на уроке математики.

1 Сначала — скобки: (2 + 3)
2 Потом — степень: 2 ** 3
3 Затем — умножение и деление: 2 * 3, 6 / 2, 7 // 2, 7 % 2
4 В самом конце — сложение и вычитание: 2 + 3, 5 − 1

Если сомневаешься — ставь скобки. Лишние не помешают, а вот пропущенные могут запутать. Пример:

print(2 + 3 * 4) # 14 (сначала * ) print((2 + 3) * 4) # 20 (сначала скобки)

Пишем калькулятор вместе

Соберём программу, которая спрашивает два числа и печатает результаты всех семи операций.

Шаг 1. Спросим два числа

Числа — целые, значит используем int(input()).

a = int(input('Первое число: ')) b = int(input('Второе число: '))

Шаг 2. Сложение и вычитание

Самые простые операции. Пробуем:

a = int(input('Первое число: ')) b = int(input('Второе число: ')) print('Сумма:', a + b) print('Разность:', a - b)
Что выведет программа
Первое число: 7
Второе число: 3
Сумма: 10
Разность: 4

Шаг 3. Умножение, деление, целое деление

Добавим остальные операции. Обрати внимание: / даёт дробное число, а // — целое.

print('Умножение:', a * b) print('Деление:', a / b) print('Целое деление:', a // b)
Что выведет программа
Первое число: 7
Второе число: 3
Сумма: 10
Разность: 4
Умножение: 21
Деление: 2.3333333333333335
Целое деление: 2
🧠 Читаем результаты

7 / 3 даёт длинное дробное число — это нормально, Python показывает всё, что «влезает». При желании можно округлить (об этом в другой раз).

А 7 // 3 показывает, что 3 полностью влезает в 7 только 2 раза — вот и ответ 2.

Шаг 4. Остаток и степень

Осталось два оператора. Добавим их:

print('Остаток:', a % b) print('Степень:', a ** b)
Что выведет программа
Первое число: 7
Второе число: 3
Остаток: 1
Степень: 343
🧠 Почему 343

7 ** 3 — это 7 × 7 × 7 = 343. Обычная степень.

А 7 % 3 — это остаток: 7 = 3 × 2 + 1. Единица — это остаток.

Три самые частые ошибки и домашнее задание

Посмотрим на классические подводные камни арифметики в Python. И получим домашку.

❌ Ошибка 1. Забыл int() — считает строки

Если input() не обернуть в int(), то складывать будет не числа, а строки.

a = input('Первое: ')
b = input('Второе: ')
print(a + b)

Если ввести 3 и 4, получится 34 — потому что строки склеились, а не сложились.

Как исправить — обернуть в int():

a = int(input('Первое: '))
b = int(input('Второе: '))
print(a + b)   # 7
❌ Ошибка 2. Деление на ноль

На ноль делить нельзя — ни в математике, ни в Python.

a = 10
b = 0
print(a / b)

Что скажет Python:

ZeroDivisionError: division by zero

Что делать: проверять, что второе число не ноль, перед делением. В простых программах — просто напоминать пользователю вводить не ноль.

❌ Ошибка 3. Путает / и //

/ — обычное деление (дробный результат). // — целое деление (отбрасывает остаток).

print(7 / 2)     # 3.5 — обычное деление
print(7 // 2)    # 3   — целое деление

Если нужно узнать «сколько целых раз» — используй //. Если хочешь точный ответ — /.

Спроси минуты. Выведи, сколько это часов и минут.

Часы = минуты // 60, минуты = минуты % 60.

3.1 Секунды в дни 🌱🌱🌱

Спроси секунды. Выведи дни, часы, минуты, секунды.

💡 Подсказка

В дне 86400 сек, в часе 3600, в минуте 60. Разбивай пошагово, используя // и %.

✅ Решение 
total = int(input('Секунд: '))

days = total // 86400
rest = total % 86400

hours = rest // 3600
rest = rest % 3600

minutes = rest // 60
seconds = rest % 60

print('Это', days, 'д', hours, 'ч', minutes, 'мин', seconds, 'с')
