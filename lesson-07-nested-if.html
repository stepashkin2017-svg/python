⏱ 14–24 минут · 🪆 Вложенный if

Матрёшка из условий

Как проверить категорию один раз, а уже внутри выбрать бренд? Разместить одно условие внутри другого — как матрёшку.

Вложенный условный оператор
Это условный оператор внутри другого условного оператора. Сначала проверяется внешнее условие. Только если оно истинно — Python заходит внутрь и проверяет внутреннее.
Сначала проверяем категорию. Если она совпала — внутри проверяем предпочтение. Если категория не совпала — во внутреннее условие Python даже не смотрит.

Смотрим на матрёшку

Внешнее условие — это большая матрёшка. Внутреннее условие спрятано у неё внутри. Чтобы добраться до внутреннего, надо сначала «открыть» внешнее.

Код с вложенным условием

category = input('Категория товара: ') wish = input('Предпочтение: ') if category == 'молочные продукты': if wish == 'фермерское': print('Экоферма') else: print('Моё село') if category == 'хлеб': if wish == 'цельнозерновой': print('Пекарня дяди Коли') else: print('Хлебозавод №21')

🧠 Как это работает — по шагам

1. Python проверяет внешнее условие — категория «молочные продукты»?
2. Если да — заходит внутрь и проверяет внутреннее условие — «фермерское»?
3. Если нет — вообще не заходит внутрь. Пропускает весь блок и идёт к следующему if.

⏱ 24–32 минут · 📐 Отступы и правила

Как оформлять вложенность

Новых правил нет. Работают те же самые, что и раньше: двоеточие после условия и отступ в 4 пробела. Просто теперь отступов два уровня.

if выражение_1: if выражение_2: print(действие_1) else: print(действие_2) else: print(действие_3)
1 Внутренний блок — +4 пробела от внешнего. Итого 8 пробелов на втором уровне.
2 Двоеточие — после каждого условия. Не забудь ни в if, ни в else.
3 else относится к ближайшему if. Следи за отступом!
⚠️ Главная ловушка — отступы

Если ошибиться в отступе, else может привязаться не к тому if. Программа либо сломается, либо начнёт работать не так, как ты ожидал.

Совет: пиши код постепенно. Сначала внешнее условие с телом. Потом внутри — вложенное. И только потом else.

Сравним три подхода к одной задаче

Задача: если приём пищи «Завтрак» — предложить кашу. Для других приёмов уточнить, хочет ли клиент поесть плотно. Если да — «Плов», иначе — «Котлета с пюре».

Составное условие
meal = input('Приём пищи:')

if meal == 'Завтрак':
    print('Каша')

if meal == 'Обед' and wish == 'плотно':
    print('Плов')

if meal == 'Обед' and wish != 'плотно':
    print('Котлета')
Цепочка elif
meal = input('Приём пищи:')

if meal == 'Завтрак':
    print('Каша')
elif meal == 'Обед':
    wish = input('Предпочтение:')
    if wish == 'плотно':
        print('Плов')
    else:
        print('Котлета')
Вложенный if (в else)
meal = input('Приём пищи:')

if meal == 'Завтрак':
    print('Каша')
else:
    wish = input('Предпочтение:')
    if wish == 'плотно':
        print('Плов')
    else:
        print('Котлета')
🧠 Когда вложенность уместна

Вложенный if — не всегда лучший выбор. Он действительно полезен, когда:

1. Второй вопрос имеет смысл только после ответа на первый. (Если приём пищи не «Завтрак», то про плотность еды спрашивать есть смысл.)
2. Ты не можешь выразить логику через and или elif.

Во всех остальных случаях лучше использовать elif — код получится короче и понятнее.

⏱ 40–45 минут · 📬 Ошибки и домашка

Три ошибки во вложенных условиях

Разберём, на чём спотыкаются новички, когда пробуют вкладывать условия друг в друга.

❌ Ошибка 1. Забыл второй уровень отступа

Внутренний if должен быть с отступом в 4 пробела от внешнего. Иначе Python решит, что это два независимых условия.

if category == 'молочные':
if wish == 'фермерское':
    print('Экоферма')

Что скажет Python:

IndentationError: expected an indented block

Как исправить — добавить отступы:

if category == 'молочные':
    if wish == 'фермерское':
        print('Экоферма')
❌ Ошибка 2. else привязался не к тому if

else всегда относится к ближайшему if, отступ которого совпадает. Если ошибиться — логика сломается.

if category == 'молочные':
    if wish == 'фермерское':
        print('Экоферма')
    else:
        print('Что-то другое')   # ← относится к внутреннему if!

Правильно — если хочешь проверить разные категории, используй вложенный if после else:

if category == 'молочные':
    if wish == 'фермерское':
        print('Экоферма')
    else:
        print('Моё село')
else:
    print('Хлеб или что-то ещё')
❌ Ошибка 3. Слишком глубокая вложенность

Три, четыре, пять уровней вложенности — почти всегда можно упростить. Такой код сложно читать.

if a:
    if b:
        if c:
            if d:
                print('всё сошлось')

Если условия независимы, соединяй их через and:

if a and b and c and d:
    print('всё сошлось')

А если это варианты одного признака — используй elif.

💡 Как быстро понять, что не так

Смотри на отступ. Отступ показывает, к какому условию относится команда. Если print стоит на 4 пробела — он во внешнем условии. Если на 8 — во внутреннем.
