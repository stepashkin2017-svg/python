Что такое стандартная библиотека

В Python много команд: одни — встроенные, другие лежат в отдельных файлах. Разберёмся, как они устроены.

Стандартная библиотека Python
Это набор готовых модулей, которые идут вместе с языком. Каждый модуль — отдельный файл с командами для определённой темы: работа со случайными числами, временем, графикой и т.д.
Модуль random — для случайных чисел.
Модуль time — для работы со временем.
Модуль turtle — для графики.
📖 Почему всё не лежит «в одном месте»

Простые команды (например, print(), input(), len()) интерпретатор знает сразу — они всегда под рукой.

А сложные и редкие команды хранятся в отдельных файлах-модулях. Чтобы ими пользоваться, модуль нужно сначала подключить к программе.

Так делают почти во всех языках программирования — чтобы программа оставалась быстрой и не тащила за собой всё сразу.

⏱ 13–20 минут · 📦 Импорт

Три способа подключить модуль

Модуль можно подключить по-разному. У каждого способа свои особенности — разберём все три на примере модуля random.

1
Подключить модуль целиком
import random

number = random.randint(0, 9)
Плюс: сразу понятно, откуда команда.
Минус: каждый раз нужно писать random.
2
Подключить одну функцию
from random import randint

number = randint(0, 9)
Плюс: короче, не нужно префикса.
Минус: если функций много — придётся перечислить их все.
3
Подключить всё подряд
from random import *

number = randint(0, 9)
Плюс: очень коротко.
Минус: имена могут конфликтовать — лучше избегать.
🧠 Как выбрать

Для учебного кода удобно использовать from random import randint — коротко и понятно.

В больших проектах предпочитают import random — так всегда видно, откуда пришла команда.

Третий способ (import *) почти не используют: слишком легко запутаться.

Импорт обычно пишется в самом начале

from random import randint # ← первой строкой number = randint(1, 6) print(number)
⚠️ Куда ставить import

Импорт ставят в самом начале файла, до других команд. Так проще увидеть, какие модули использует программа.

Две главные функции модуля random

В модуле random много функций, но нам сейчас понадобятся две.

ФункцияЧто делает
randint(a, b) Случайное целое число от a до b включительно
random() Случайное дробное от 0 (включительно) до 1 (не включительно)

⚠️ Правая граница ВХОДИТ

В randint(1, 6) могут выпасть все шесть чисел: 1, 2, 3, 4, 5 и 6. Оба конца входят.

Это отличается от range(1, 6) из прошлых уроков, где правая граница не входит. Будь внимателен!

random() — дробное от 0 до 1

Вторая полезная функция. Она возвращает дробное число — от 0 (включительно) до 1 (не включительно).

import random x = random.random() print(x)
Примеры
0.4728391
0.9140226
0.0385011
🧠 Где пригодится

Может показаться, что это бесполезно: всегда какое-то число от 0 до 1. Но на самом деле так генерируют любые случайные величины — просто умножают на нужное число.

Например, random() * 100 даст случайное число от 0 до 100. А randint(1, 100) — целое в том же диапазоне.

Решаем задачи «Go Ahead!»

Теперь у Байта есть все инструменты, чтобы справиться с заказом. Разберём две задачи спортивной компании.

Задача 1. Жеребьёвка команд по водному поло

Программа спрашивает число команд N и печатает случайную пару номеров от 1 до N.

from random import randint total = int(input('Число участвующих команд: ')) participant_1 = randint(1, total) participant_2 = randint(1, total) print('Команда', participant_1, '— команда', participant_2)
Что выведет программа
Число участвующих команд: 11
Команда 7 — команда 4

Число участвующих команд: 9
Команда 5 — команда 1
🧠 Разбор

1. Спрашиваем число команд — граница диапазона.
2. Дважды вызываем randint(1, total) — получаем два случайных номера.
3. Печатаем их как пару.

Если выпадут одинаковые числа — это нормально: судья просто запустит программу ещё раз.

Задача 2. Распределение футболистов по командам

Тренер вводит имена спортсменов по одному. Программа случайно отправляет каждого в команду 1 или в команду 2.

from random import randint name = input('Имя спортсмена (off — завершить): ') while name != 'off': team = randint(1, 2) print(name, ', команда', team) name = input('Имя спортсмена (off — завершить): ')
Что выведет программа
Имя спортсмена (off — завершить): Катя
Катя , команда 2
Имя спортсмена (off — завершить): Лера
Лера , команда 1
Имя спортсмена (off — завершить): Василиса
Василиса , команда 1
Имя спортсмена (off — завершить): Полина
Полина , команда 2
Имя спортсмена (off — завершить): off

Программа может отправить всех в одну команду — равное количество обеспечивает тренер, а не программа.

🧠 Знакомая структура

Это та же конструкция, что мы использовали для промокодов и отзывов: спрашиваем до тех пор, пока не введут «off».

Только теперь внутри цикла не проверка, а случайный выбор команды для каждого имени.

Сравним два решения

ЗадачаЧто спрашиваемЧто генерируем
Жеребьёвка Число команд N Два номера randint(1, N)
Футболисты Имена по одному Один номер команды randint(1, 2)
💡 Что общего и что разное

Общее: в обоих случаях используем randint() — только с разными границами.

Разное: в первой задаче вызываем функцию ровно два раза, во второй — по разу для каждого спортсмена, внутри цикла while.

05 Распределение по командам 🌱🌱

Спрашивай имена спортсменов, пока не введут «off». Каждому выпадает команда 1 или 2.

💡 Подсказка

Внутри цикла team = randint(1, 2).

✅ Решение 
from random import randint

name = input("Имя спортсмена (off — стоп): ")
while name != "off":
    team = randint(1, 2)
    print(name, ", команда", team)
    name = input("Имя спортсмена (off — стоп): ")
06 Случайный комплимент 🌱🌱🌱

Выбери одну из трёх фраз случайно: «Ты молодец!», «Отличная работа!», «Так держать!»

💡 Подсказка

Сгенерируй randint(1, 3) и через if/elif/else выбери фразу.

✅ Решение 
from random import randint

n = randint(1, 3)
if n == 1:
    print("Ты молодец!")
elif n == 2:
    print("Отличная работа!")
else:
    print("Так держать!")
07 Своя программа 🌱🌱🌱

Придумай свою программу с использованием случайных чисел. Например, игра «Камень-ножницы-бумага» или случайный прогноз погоды.

💡 Подсказка

Комбинируй random с условиями и циклами.

✅ Решение (камень-ножницы-бумага) 
from random import randint

variants = ["камень", "ножницы", "бумага"]
print("1 — камень, 2 — ножницы, 3 — бумага")
player = int(input("Ваш выбор: "))
comp = randint(1, 3)
print("Компьютер выбрал:", variants[comp - 1])
if player == comp:
    print("Ничья!")
elif (player == 1 and comp == 2) or (player == 2 and comp == 3) or (player == 3 and comp == 1):
    print("Вы победили!")
else:
    print("Компьютер победил!")
