⏱ 0–6 минут · 🤔 Постановка задачи

Когда двух ветвей мало

У Байта в арсенале уже есть классический if / else и вложенный if. Но вот задача, где и то, и другое — неудобно.

🤖
Звонят из школы. Просят программу-помощника: спрашиваем оценку — и печатаем, что она значит. Оценок четыре: 5, 4, 3, 2. Как мне это сделать через обычный if / else? Придётся вкладывать условия друг в друга — три уровня! Кошмар какой-то.

Попробуем вложенным if

if mark == 5: print('Отлично') else: if mark == 4: print('Хорошо') else: if mark == 3: print('Удовлетворительно') else: print('Надо повторить')

Работает? Да. Но посмотри, что творится с отступами: они растут как ёлочка. Чем больше вариантов — тем глубже вложенность. А если вариантов десять?

⚠️ Проблема «лестницы»

Каждое новое «иначе если…» добавляет ещё один уровень вложенности. Такой код трудно читать и легко запутаться с отступами.

К счастью, в Python для этого есть специальный инструмент — он делает то же самое, но в один уровень. Давай познакомимся.

🤖
О! А можно как-то по-другому? Чтобы условия стояли не «внутри» друг друга, а друг за другом?
⏱ 6–14 минут · 🌳 elif

elif — «а если другое?»

Вместо вложенности — цепочка. Условия стоят один за другим, на одном уровне. За это отвечает ключевое слово elif.

elif
Сокращение от «else if» — «иначе если». Проверяет своё условие только если все предыдущие оказались ложными. Ветвей elif может быть сколько угодно.
«Если if не подошло — проверь elif. Если и оно не подошло — проверь следующее elif. Если совсем ничего не подошло — сработает else.»

Тот же пример с оценками, но через elif

if mark == 5: print('Отлично') elif mark == 4: print('Хорошо') elif mark == 3: print('Удовлетворительно') else: print('Надо повторить')

Код стал плоским: все условия на одном уровне, ни одного лишнего отступа. Читается как оглавление — сверху вниз.

Как выглядит «лестница» условий

if Если первое условие истинно → выполняем его ветку и выходим из цепочки.
elif Иначе если это условие истинно → выполняем его ветку и выходим.
elif Иначе если вот это истинно → выполняем эту ветку и выходим.
else Если ни одно из условий выше не подошло → выполняем эту ветку.
1Цепочка всегда начинается с одного if.
2Между if и else может быть сколько угодно elif.
3else — необязателен. Если его нет и ни одно условие не сработало — просто ничего не делаем.
4Все ветви — на одном уровне отступа. Никакой вложенности!
🧠 elif vs вложенный if

Вложенный if — когда второй вопрос имеет смысл только после первого. Например: «Ты взрослый? Если нет — есть ли сопровождающий?»

elif — когда варианты равноправны: либо один, либо другой, либо третий. «Оценка 5, 4, 3 или 2?»

⏱ 14–22 минут · 🧠 Как работает цепочка

Python идёт сверху вниз и останавливается

Как только находится первое истинное условие — Python выполняет его ветку и выходит из всей цепочки. Остальные elif даже не проверяются!

Симулятор: машина оценок

🎓
Пройди по цепочкеВведи оценку и посмотри, какие условия Python проверяет
1mark = int(input('Оценка: ')) 2if mark == 5: 3 print('Отлично ⭐') 4elif mark == 4: 5 print('Хорошо 👍') 6elif mark == 3: 7 print('Удовлетворительно') 8else: 9 print('Надо повторить')
💡Попробуй 5, 4, 2. Заметь: как только ветка нашлась — остальные условия не проверяются.
🧠 Почему это важно

Если ты поставишь два одинаковых условия в цепочку — сработает только первое. Второе Python даже не посмотрит. А если поставить условия в неверном порядке — можно получить не тот результат (об этом следующий шаг).

⏱ 22–32 минут · ⚠️ Порядок условий

Порядок ветвей — критичен!

Одна и та же программа может давать разные ответы — в зависимости от того, в каком порядке стоят условия. Разберём на примере баллов: 0–100.

Задача

Есть балл от 0 до 100. Нужно напечатать: 90+ → «отлично», 70+ → «хорошо», 50+ → «удовлетворительно», иначе → «плохо».

✅От строгого к мягкому
if n >= 90:
    print('отлично')
elif n >= 70:
    print('хорошо')
elif n >= 50:
    print('удовл')
else:
    print('плохо')
n = 75 → напечатает: хорошо
❌От мягкого к строгому
if n >= 50:
    print('удовл')
elif n >= 70:
    print('хорошо')
elif n >= 90:
    print('отлично')
else:
    print('плохо')
n = 75 → напечатает: удовл
⚠️ Почему так происходит

Python проверяет условия по очереди. Если первым стоит мягкое условие (n >= 50), оно перехватит все числа, начиная с 50. До строгих проверок дело не дойдёт.

Правило: ставь условия от самого строгого к самому мягкому — от большего к меньшему, от узкого к широкому.

🧠 Как запомнить

Представь воронку: сначала отсеиваем узкий случай (совсем отличников), потом пошире, и только в самом конце — всё, что осталось, уходит в else.

⏱ 40–45 минут · 📬 Ошибки и домашка

Три самые частые ошибки

Разберём, на чём спотыкаются новички в цепочке elif.

❌Ошибка 1. Неверный порядок условий

Условия проверяются сверху вниз. Мягкое условие первым — перехватит всё.

if n >= 50:
    print('удовл')       # ← перехватит всё, что ≥ 50
elif n >= 90:
    print('отлично')     # ← никогда не сработает

Как исправить — переставить от большего к меньшему:

if n >= 90:
    print('отлично')
elif n >= 70:
    print('хорошо')
elif n >= 50:
    print('удовл')
else:
    print('плохо')
❌Ошибка 2. Написал else if вместо elif

В Python нельзя писать «else if» через пробел — только elif.

if x == 1:
    print('один')
else if x == 2:      # ← SyntaxError
    print('два')

Как исправить:

if x == 1:
    print('один')
elif x == 2:
    print('два')
❌Ошибка 3. Двоеточие только у if

Двоеточие ставится после каждой ветки: if, elif, else.

if x == 1:
    print('один')
elif x == 2
    print('два')      # ← нет двоеточия
else
    print('другое')   # ← нет двоеточия

Как исправить:

if x == 1:
    print('один')
elif x == 2:
    print('два')
else:
    print('другое')
