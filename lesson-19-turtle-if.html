Программа контроля скорости

Теперь соберём всё вместе. У нас есть условие — про скорость, и есть команды turtle — про рисование. Соединим их.

Разберём по шагам

1 Подключаем turtle.
2 Спрашиваем скорость у пользователя.
3 Проверяем: скорость больше 60?
4 В зависимости от ответа — вызываем свою функцию рисования.
🎨 Каждая картинка — своя функция

Мы уже умеем выносить рисунок в функцию. Сделаем две функции: draw_ok() — рисует зелёный круг, и draw_warning() — рисует восклицательный знак.

А в основной программе — просто вызовем нужную функцию в зависимости от скорости.

Функция с восклицательным знаком

Прежде чем собирать всё вместе — разберёмся, как нарисовать восклицательный знак. Это две фигуры: вертикальная палочка и точка под ней.

def draw_warning(): color('red') pensize(8) # вертикальная палочка penup() goto(0, 100) pendown() goto(0, 30) # точка penup() goto(0, 0) pendown() circle(8)
🧠 Что здесь нового

pensize(8) — делаем перо толще, чтобы палочка была заметная. penup() и pendown() — чтобы перейти к точке, не оставив следа.

Функция с зелёным кругом

def draw_ok(): color('green') begin_fill() circle(60) end_fill()

Основная программа с условием

from turtle import * speed(10) def draw_ok(): color('green') begin_fill() circle(60) end_fill() def draw_warning(): color('red') pensize(8) penup() goto(0, 100) pendown() goto(0, 30) penup() goto(0, 0) pendown() circle(8) speed_value = int(input('Введите скорость транспорта: ')) if speed_value > 60: draw_warning() else: draw_ok() hideturtle() exitonclick()
Что выведет программа
Введите скорость транспорта: 75

Откроется окно с красным восклицательным знаком
(скорость 75 > 60 — превышение)

Введите скорость транспорта: 45

Откроется окно с зелёным кругом
(скорость 45 ≤ 60 — всё в порядке)
🧠 Разбор по шагам

1. Программа спрашивает скорость и сохраняет её в переменную.
2. Проверяет условие speed_value > 60.
3. Если скорость больше 60 — Python вызывает функцию draw_warning().
4. Если нет — вызывается draw_ok().
5. Рисуется только одна фигура — та, что выбрана по условию.

⚠️ Важно: отступы

Вызовы draw_warning() и draw_ok() стоят с отступом под if и else. Это говорит Python: «эти команды — часть условия».

Если убрать отступ — обе функции вызовутся подряд, независимо от скорости. Так делать нельзя!

Светофор по времени суток

Полиция довольна табло скорости. Но работы много — теперь нужен светофор для перекрёстка. А ещё его надо рисовать по-разному: днём и ночью.

🤖
Смотри, какая задача. Программа спрашивает время суток. Если «день» — рисует светофор с яркими цветами. Если «ночь» — светофор с тёмными, приглушёнными оттенками. И ещё нужно добавить фон: белый днём, тёмно-синий ночью.

Идея

Снова два варианта → снова if / else. Но теперь в каждой ветке вызовем функцию с параметром: цвет кругов будет меняться.

def draw_light(y, cur_color): penup() goto(0, y) pendown() color(cur_color) begin_fill() circle(40) end_fill()
🧠 Что принимает функция

draw_light(y, cur_color) — рисует один круг светофора. y — координата по вертикали (где будет круг). cur_color — какой цвет ему дать.

Так одной функцией можно нарисовать все три круга — просто передавая разные координаты и цвета.

Дневной светофор

def draw_day_traffic(): bgcolor('white') draw_light(80, 'red') draw_light(0, 'yellow') draw_light(-80, 'green')

Ночной светофор

def draw_night_traffic(): bgcolor('midnightblue') draw_light(80, 'darkred') draw_light(0, 'goldenrod') draw_light(-80, 'darkgreen')

Основная программа

from turtle import * speed(10) # ... обе функции draw_day_traffic и draw_night_traffic ... time_of_day = input('Сейчас день или ночь? ') if time_of_day == 'день': draw_day_traffic() else: draw_night_traffic() hideturtle() exitonclick()
⚠️ Команда bgcolor()

bgcolor('white') — красит фон окна в белый цвет. bgcolor('midnightblue') — в тёмно-синий. Это и даёт эффект «день / ночь».

Три варианта — а if умеет только два?

Оказывается, условий может быть больше двух. Например, время суток бывает не только «день» или «ночь» — бывает ещё «утро» и «вечер».

🤖
Новая задача: городской пейзаж. Утром — оранжевое небо, днём — голубое, вечером — розовое, ночью — тёмное. Если я напишу через два if / else, получится путаница. Есть ли способ проще?

Вспоминаем elif

Мы уже встречались с этой конструкцией в уроке 6. Когда вариантов больше двух, между if и else можно вставить сколько угодно elif.

if условие_1: действие_1 elif условие_2: действие_2 elif условие_3: действие_3 else: действие_по_умолчанию
🧠 Читается как «если … иначе если … иначе»

Программа идёт по ветвям сверху вниз и останавливается на первой истинной. Всё остальное пропускается.

Пейзаж по времени суток

from turtle import * speed(10) moment = input('Время суток (утро/день/вечер/ночь): ') if moment == 'утро': bgcolor('lightyellow') elif moment == 'день': bgcolor('skyblue') elif moment == 'вечер': bgcolor('plum') else: bgcolor('midnightblue') # а дальше — общий рисунок (например, солнце) color('gold') begin_fill() circle(50) end_fill() hideturtle() exitonclick()
🧠 Как это работает

1. Программа спрашивает время суток.
2. Идёт по ветвям: подходит «утро»? Если да — жёлтый фон. Если нет — проверяем «день». И так далее.
3. Если ничего не подошло — сработает else: тёмный фон «ночь».
4. После выбора фона рисуется общий рисунок — солнце. Он не зависит от времени суток.

⚠️ Что общего и что разное

Разное — только цвет фона. Он выбирается по условию.

Общее — солнце. Оно рисуется после цепочки условий, для всех случаев. Поэтому команды рисования солнца стоят без отступа.

01 Чётное или нет 🌱

Спроси число. Если оно чётное — нарисуй зелёный круг, иначе — красный.

💡 Подсказка

Проверка чётности — n % 2 == 0. А цвет задаётся через color().

✅ Решение 
from turtle import *

n = int(input("Число: "))
if n % 2 == 0:
    color("green")
else:
    color("red")

begin_fill()
circle(60)
end_fill()

exitonclick()
02 Возраст и поезд 🌱

Спроси возраст. Если 18 или больше — нарисуй синюю стрелку вперёд. Иначе — красный круг «нельзя».

💡 Подсказка

Условие: age >= 18. Для стрелки используй forward() с pensize(10).

✅ Решение 
from turtle import *

age = int(input("Возраст: "))
if age >= 18:
    color("blue")
    pensize(10)
    forward(150)
else:
    color("red")
    begin_fill()
    circle(60)
    end_fill()

exitonclick()
03 Знак скорости 🌱🌱

Классическая задача урока: спроси скорость. Если больше 60 — красный восклицательный знак. Иначе — зелёный круг.

💡 Подсказка

Вынеси обе картинки в функции draw_warning() и draw_ok(), потом вызови нужную.

✅ Решение 
from turtle import *
speed(10)

def draw_ok():
    color("green")
    begin_fill()
    circle(60)
    end_fill()

def draw_warning():
    color("red")
    pensize(8)
    penup(); goto(0, 100); pendown()
    goto(0, 30)
    penup(); goto(0, 0); pendown()
    circle(8)

speed_value = int(input("Скорость: "))
if speed_value > 60:
    draw_warning()
else:
    draw_ok()

hideturtle()
exitonclick()

05 Который час? 🌱🌱🌱

Спроси час (0–23). Утро (6–11) — жёлтый фон. День (12–17) — голубой. Вечер (18–21) — розовый. Ночь — тёмный.

💡 Подсказка

Здесь удобно использовать if / elif / elif / else. Проверяй границы через >= и <=.

✅ Решение 
from turtle import *

h = int(input("Час: "))
if 6 <= h <= 11:
    bgcolor("lightyellow")
elif 12 <= h <= 17:
    bgcolor("skyblue")
elif 18 <= h <= 21:
    bgcolor("plum")
else:
    bgcolor("midnightblue")

07 Оценка 🌱🌱🌱

Спроси оценку (1–5). Нарисуй столько звёзд, сколько получил. Звёзды рисуются через цикл внутри каждой ветви.

💡 Подсказка

Для каждой оценки — свой цикл for i in range(N). Используй penup(), goto(), pendown(), чтобы располагать звёзды в ряд.

✅ Решение (звёздочками-кружками) 
from turtle import *

mark = int(input("Оценка (1-5): "))

color("gold")
x = -150
for i in range(mark):
    penup()
    goto(x, 0)
    pendown()
    begin_fill()
    circle(30)
    end_fill()
    x += 80

hideturtle()
exitonclick()
08 Найди и исправь 🌱🌱🌱

Программа должна рисовать зелёный круг, если скорость в норме, и красный — если нет. Но она всегда рисует красный. Найди ошибку.

💡 Подсказка

Проверь условие. Возможно, стоит неправильный знак сравнения — вместо <= стоит > или наоборот.

✅ Решение 
from turtle import *

speed_value = int(input("Скорость: "))

if speed_value <= 60:
    color("green")
else:
    color("red")
