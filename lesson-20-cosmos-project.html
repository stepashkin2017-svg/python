💡 Как начать работать в Playground

В Playground есть две вкладки — одна для модуля, другая для основной программы. Сначала пиши код в модуле (это будет файл space.py), потом — в главной.

Начни с одной самой простой функции — например, draw_planet(). Проверь, что она работает. Только потом переходи к следующей.

💡 Что писать в модуле?

Внутри модуля — только определения функций. Каждая функция:

1. Поднимает перо: penup().
2. Переходит в нужную точку: goto(x, y).
3. Опускает перо: pendown().
4. Рисует объект — через circle(), forward(), left() и т. д.

Никаких input(), while и вызовов функций внутри модуля быть не должно.

💡 Как нарисовать звёзды циклом

Сначала импортируй random в модуле (from random import randint).

Потом в функции используй цикл на 30–40 итераций. На каждой итерации:

1. Случайные координаты: x = randint(-180, 180), y = randint(-130, 130).
2. Переходи в точку через goto().
3. Рисуй маленькую точку: dot(3, 'white') — если используешь команду dot(), или маленький круг.

💡 Как нарисовать ракету

Ракета состоит из трёх частей:

1. Нос — треугольник. Можно через forward() и left(120).
2. Корпус — прямоугольник или овал. Овал можно сымитировать парой кругов.
3. Пламя — треугольник под корпусом.

Начинай рисовать сверху вниз — так удобнее. Не забудь в конце вернуться в точку старта.

💡 Какую структуру имеет основная программа

Основная программа короткая — не более 15 строк:

import space from turtle import * speed(10) bgcolor('black') space.draw_stars() space.draw_planet() space.draw_rocket() hideturtle() exitonclick()

Важно: import space пишется первой строкой. Иначе Python не найдёт модуль.

💡 Частые ошибки

1. Забыл import space — будет NameError.
2. Написал import space.py вместо import space — ошибка.
3. Функция в модуле использует input() — не нужно, модуль не должен ничего спрашивать.
4. Забыл penup() перед goto() — между объектами будут лишние линии.
5. Забыл hideturtle() в основной программе — черепашка останется на экране.

Файл 1 — модуль space.py:

space.py
from random import randint

def draw_stars():
    penup()
    color('white')
    for i in range(40):
        x = randint(-180, 180)
        y = randint(-130, 130)
        goto(x, y)
        dot(3, 'white')

def draw_planet():
    penup()
    goto(-150, 80)
    pendown()
    color('violet')
    begin_fill()
    circle(50)
    end_fill()
    # кольца планеты
    penup()
    goto(-200, 80)
    pendown()
    pensize(3)
    color('light blue')
    for i in range(2):
        circle(50, 90)
        right(90)

def draw_rocket():
    penup()
    goto(120, -100)
    pendown()
    color('white')
    begin_fill()
    forward(60)
    left(120)
    forward(60)
    left(120)
    forward(60)
    end_fill()
    # пламя
    penup()
    goto(120, -160)
    pendown()
    color('orange')
    begin_fill()
    forward(30)
    left(120)
    forward(30)
    left(120)
    forward(30)
    end_fill()

def draw_satellite():
    penup()
    goto(0, -60)
    pendown()
    color('gray')
    begin_fill()
    for i in range(4):
        forward(40)
        left(90)
    end_fill()
    # антенна
    penup()
    goto(20, -20)
    pendown()
    color('yellow')
    dot(8, 'yellow')

Файл 2 — основная программа main.py:

main.py
import space
from turtle import *

speed(10)
bgcolor('midnightblue')

space.draw_stars()
space.draw_planet()
space.draw_rocket()
space.draw_satellite()

hideturtle()
exitonclick()
🧠 Разбор решения

1. В модуле space.py четыре функции — каждая рисует свой объект. Все они начинают с penup(), чтобы перейти в нужное место без лишних линий.

2. Функция draw_stars() использует random и цикл на 40 итераций: рисует dot() в случайных точках.

3. Основная программа короткая: импорт, фон, четыре вызова функций, скрытие черепашки.

4. Ты можешь менять координаты, цвета и размеры как угодно — лишь бы все объекты влезали на экран.
