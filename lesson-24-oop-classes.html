⏱ 18–34 минут · 🔍 Разбор конструкции

Конструкция класса — разбираем по шагам

Теперь самое важное. Разберём наш собственный класс Hero строчка за строчкой. Каждую часть я объясню отдельно — и ты поймёшь, что ничего сложного тут нет.

Вот так выглядит полный класс Hero

class Hero(): def __init__(self, name, health, armor, power, weapon): self.name = name self.health = health self.armor = armor self.power = power self.weapon = weapon def print_info(self): print('Герой:', self.name) print('Здоровье:', self.health)

Сейчас мы разберём это по частям. Запомни главное: класс — это просто коробка с двумя-тремя строчками особого вида. Разберёмся, что в каждой.

🔹 Подшаг 1. Строка class Hero():

Это самая первая строчка — она говорит Python: «сейчас я опишу новый класс».

class Hero ():
class Ключевое слово. Означает «объявляю новый класс». Пишется всегда маленькими буквами.
Hero Имя класса. Придумываем сами. Пишем с большой буквы — так принято. Имя — как заголовок в книге, оно даёт всему классу название.
(): Круглые скобки + двоеточие. Скобки пока просто пустые (мы ни от кого не наследуемся). Двоеточие означает: «всё, что ниже с отступом — это тело класса».
⚠️ Что важно помнить

После строки с class идёт двоеточие :, а всё содержимое класса пишется с отступом. Как мы уже делали с if и for.

Без отступа Python решит, что класс закончился, и следующая строка к нему уже не относится.

🔹 Подшаг 2. Строка def __init__(self, name, ...)

Вторая строка внутри класса — самая загадочная. Тут всё в необычных подчёркиваниях и в слове self. Разберём её по кусочкам.

def __init__ ( self , name, health, ...):
def Ключевое слово «объявляю функцию». Мы уже его знаем.
__init__ Особое имя. Это конструктор — функция, которая вызывается автоматически, когда создаётся новый герой. Слово «init» по-английски значит «инициализация, начальная настройка». Два подчёркивания с двух сторон — знак, что это зарезервированное имя в Python.
self Первый параметр, обязательный. Это сам объект. «Self» по-английски — «сам». Подробно разберём ниже, в подшаге 3.
name, health, ... Остальные параметры. Какие данные ты хочешь передать новому герою при создании. Мы решили передавать: имя, здоровье, броню, силу удара и оружие.
🧠 Простыми словами

def __init__ — это инструкция «как собрать нового героя». Python выполняет её автоматически, как только ты пишешь Hero(...).

А раз это функция, её можно вызывать не вручную, а через команду создания объекта — Python сделает это сам.

🔹 Подшаг 3. Что такое self?

Это самое непонятное слово для новичка. Но идея — простая.

🤖
Представь, что в классе Hero сидят несколько героев. Когда один из них говорит «моё имя — Ричард», он имеет в виду именно себя, а не соседа. Слово self как раз это и означает: «я, тот объект, который сейчас выполняется».
🛡️
knight
name = 'Ричард'
health = 50
≠
🏹
rascal
name = 'Питер'
health = 20
Когда мы пишем self.name внутри метода, Python подставляет того самого героя, у которого вызван метод. У knight это будет «Ричард», у rascal — «Питер».
🧠 Как это работает в памяти

Каждый герой помнит только свои данные. И когда метод говорит self.name, он обращается к своему собственному свойству, а не к чужому.

⚠️ Важное правило

Первый параметр любого метода в классе всегда называется self. Это договорённость Python.

Внутри метода обращаться к свойствам объекта можно только через self: self.name, self.health. Просто name не сработает.

🔹 Подшаг 4. Тело конструктора — создаём свойства

Внутри __init__ мы пишем строки вида self.имя = имя. Каждая такая строчка создаёт у героя новое свойство.

self.name = name
self «Я — тот самый герой, который сейчас создаётся».
.name Имя свойства. Точка после self означает: «возьми у меня свойство name».
= Знак присваивания. Положи то, что справа, в то, что слева.
name Параметр функции. Значение, которое пришло от вызова Hero('Ричард', ...).

Читается так: «У меня (self) есть свойство name, и оно равно параметру name, который пришёл извне».

📥 Что приходит в __init__
name 'Ричард'
health 50
armor 25
power 20
weapon 'меч'
📦 Что записалось в объект
self.name 'Ричард'
self.health 50
self.armor 25
self.power 20
self.weapon 'меч'
🧠 Что происходит

Параметры в конструкторе — это то, что приходит извне. А свойства через self — это то, что объект оставляет себе на память. Мы буквально «перекладываем» данные из входных параметров внутрь объекта.

Поэтому важно различать: name — параметр функции, а self.name — свойство объекта. Это разные вещи, хотя и пишутся похоже.

🔹 Подшаг 5. Обычный метод — def print_info(self):

После конструктора можно написать сколько угодно обычных методов. Они выглядят почти как функции, только обязательно принимают self первым параметром.

def print_info (self):
def Объявляем функцию. Ничего нового — то же слово, что и раньше.
print_info Имя метода. Придумали сами.
(self) Единственный параметр — self. Мы говорим: «этот метод работает с самим объектом».

Внутри метода можно обращаться к свойствам через self:

def print_info(self): print('Герой:', self.name) print('Здоровье:', self.health)
🧠 Как вызывать метод

Снаружи метода мы пишем: knight.print_info(). В скобках ничего не передаём — Python сам подставит knight в качестве self.

То есть вызов knight.print_info() для Python означает: «вызови метод print_info у объекта knight, и внутри метода self будет равно knight».

🔹 Подшаг 6. Собираем всё вместе — полный класс

Вот как выглядит класс Hero, когда мы соединили все части:

# 1. Объявляем класс с именем Hero class Hero(): # 2. Конструктор — вызывается при создании объекта def __init__(self, name, health, armor, power, weapon): # 3. Создаём свойства через self self.name = name self.health = health self.armor = armor self.power = power self.weapon = weapon # 4. Обычный метод def print_info(self): print('Герой:', self.name) print('Здоровье:', self.health) print('Оружие:', self.weapon)

Что происходит при создании героя

Строка knight = Hero('Ричард', 50, 25, 20, 'меч') запускает целую цепочку действий. Разберём её как фильм по кадрам.

1Python видит Hero(...)
Понимает: «надо создать новый объект класса Hero». Находит класс в программе.
2Автоматически вызывает __init__
Ты не пишешь __init__ вручную — Python сам вызывает конструктор, когда ты создаёшь объект.
3Создаёт пустой объект и передаёт его как self
Внутри __init__ появляется пустой «ящик», который пока ничего не знает о себе. Этот ящик и есть self.
4Заполняет свойства
По очереди выполняется self.name = 'Ричард', self.health = 50 и так далее. Пустой ящик наполняется данными.
5Возвращает заполненный объект наружу
Когда __init__ закончился, готовый объект «вылетает» наружу — и попадает в переменную knight.
6Теперь с knight можно работать
Можно вызывать knight.print_info(), менять свойства, бить врагов. Всё готово!

06 Метод strike 🌱🌱🌱

Допиши классу Hero метод strike(enemy), который уменьшает здоровье врага на силу удара.

💡 Подсказка

enemy.health -= self.power. Не путай self (себя) и enemy (врага).

07 Бой до победы 🌱🌱🌱

Допиши классу метод fight(enemy), который бьёт по очереди, пока один не победит.

💡 Подсказка

Цикл while работает, пока у обоих здоровье больше нуля.

✅ Решение 
class Hero():
    def __init__(self, name, health, power):
        self.name = name
        self.health = health
        self.power = power

    def strike(self, enemy):
        enemy.health -= self.power

    def fight(self, enemy):
        while self.health > 0 and enemy.health > 0:
            self.strike(enemy)
            if enemy.health <= 0:
                print(enemy.name, 'побеждён!')
                return
            enemy.strike(self)
            if self.health <= 0:
                print(self.name, 'побеждён!')
                return

knight = Hero('Ричард', 50, 20)
rascal = Hero('Питер', 30, 5)
knight.fight(rascal)
08 Найди и исправь 🌱🌱🌱

Класс написан с ошибками: пропущен self, перепутаны параметры. Найди и исправь.

💡 Подсказка

Первый параметр метода — всегда self. Свойства создаются как self.имя = имя.

✅ Решение 
class Hero():
    def __init__(self, name, health):
        self.name = name
        self.health = health

    def print_info(self):
        print(self.name, self.health)

knight = Hero('Ричард', 50)
knight.print_info()
