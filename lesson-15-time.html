⏱ 0–5 минут · 💭 Задача секундомера

«Спасибо за жеребьёвку! Но есть новая задача»

Менеджер «Go Ahead!» доволен: программа жеребьёвки работает без ошибок. Но на соревнованиях по плаванию нужны секундомеры.

🤖
Задача: написать программу-секундомер для заплыва кролем на 50 метров. Судья нажимает «1» — старт, а когда пловец финиширует — «0». Программа показывает, сколько секунд длился заплыв.
Что должна вывести программа
1 — старт, 0 — стоп: 1
0 — стоп: 0
Общее время: 2.73 с

1 — старт, 0 — стоп: 1
0 — стоп: 0
Общее время: 3.21 с

Знакомая структура: спрашиваем «1» до старта, потом ждём «0». Но появляется новая задача — посчитать разницу во времени между двумя моментами.

🤖
Я уже знаю про модуль random. Наверняка в стандартной библиотеке есть и модуль про время! Как он называется?
💭 Идея

Модуль для работы со временем называется time. Он, как и random, входит в стандартную библиотеку — устанавливать ничего не нужно.

Научимся брать «момент времени» дважды и считать разницу. А ещё делать паузы — это иногда тоже бывает нужно.

⏱ 5–13 минут · ⏱ time()

Функция time() — сколько секунд прошло

Чтобы посчитать разницу во времени, компьютеру нужно уметь «отметить момент». Для этого есть функция time().

time()
Возвращает количество секунд, прошедших с «начала эпохи» — 1 января 1970 года.
Результат — большое число, например 1735689600.5. Каждую секунду оно растёт.

Смотрим, как растёт

1735689600.00
Столько секунд прошло с 1 января 1970 года. Число увеличивается каждую секунду.

Кажется бесполезным? Но если мы возьмём два таких числа в разных моментах и вычтем одно из другого — получим количество секунд между ними. Это и есть основа секундомера.

from time import time start = time() # ... что-то происходит ... end = time() total = end - start print(total)
🧠 Почему так работает

time() — как секундная стрелка на огромных часах. Она движется вперёд. Мы записываем, где стрелка была в начале, и где оказалась в конце. Разница — сколько времени прошло.

Способы импорта — такие же, как у random

СпособПример
Весь модуль import time → time.time()
Одна функция from time import time → time()
Всё сразу from time import * → time()

Пауза и округление

Кроме time(), в модуле есть ещё несколько полезных функций. Разберём две самые нужные.

sleep(seconds)
Останавливает программу на указанное количество секунд. Пока идёт пауза — ничего не выполняется.
sleep(5) — программа «замрёт» на 5 секунд.
round(number, digits)
Округляет число до указанного количества знаков после точки. Это встроенная функция Python, не из модуля time.
round(2.7301, 2) → 2.73

Смотрим на паузу

Программа с паузами: печатает шаги с интервалом 1 секунда.

Шаг 1
Шаг 2
Шаг 3
Готово
from time import sleep print('Старт') sleep(3) # пауза 3 секунды print('Прошло три секунды!')
⚠️ Не увлекайся паузами

sleep(10) — это долго. Программа просто «стоит». Используй паузы, только когда они действительно нужны: например, чтобы показать анимацию или дать пользователю время прочитать сообщение.

Округление в секундомере

Разница двух времён почти всегда получается с длинным хвостом цифр. Согласись: «2.7301847372 с» — некрасиво. Округлим до двух знаков:

from time import time start = time() sleep(2) end = time() total = round(end - start, 2) print(total)
Что выведет программа
2.01

Получилось почти 2 секунды. Небольшая разница (2.01 вместо 2.00) — потому что компьютер тоже тратит время на выполнение команд.

⏱ 20–30 минут · 🏊 Секундомер

Секундомер для заплыва кролем

Собираем всё вместе: time() + round() и структуру с двумя циклами while.

План программы

1 Спрашиваем «1» до тех пор, пока не начнут.
2 Запоминаем момент старта: start = time().
3 Спрашиваем «0» до тех пор, пока не остановят.
4 Запоминаем момент финиша, считаем разницу и округляем.

Полный код

from time import time stopwatch = input('1 — старт: ') while stopwatch != '1': print('Введите 1, чтобы начать') stopwatch = input('1 — старт: ') start = time() # запомнили момент старта stopwatch = input('0 — стоп: ') while stopwatch != '0': print('Введите 0, чтобы остановить') stopwatch = input('0 — стоп: ') end = time() # запомнили момент финиша total = round(end - start, 2) print('Общее время:', total, 'с')
Что выведет программа
1 — старт: 1
0 — стоп: 0
Общее время: 3.21 с

Попробуй сам

Это настоящий секундомер — работает на твоём компьютере прямо сейчас. Нажми «Старт», подожди, потом — «Стоп».

0.00
🧠 Разбор

Первый while гарантирует, что пользователь введёт «1». Пока не введёт — программа не сдвинется.

start = time() — фиксируем момент. Потом ждём «0».

end - start — сколько секунд прошло. Округляем до сотых, чтобы не пугать длинным хвостом цифр.

⏱ 30–40 минут · ♟️ Быстрые шахматы

Таймер для быстрых шахмат

Вторая задача от «Go Ahead!» — на этот раз для шахматного турнира. Разберём более сложный пример: считаем не общее время, а оставшееся.

🤖
Задача: в быстрых шахматах игроку даётся 30 минут на все ходы. Программа спрашивает ход за ходом и говорит, сколько минут осталось. Если игрок вводит «off» или время вышло — программа завершается.
Что должна вывести программа
Ваш ход (off — сдаться): E2-E4
Осталось 29 минут из 30
Ваш ход (off — сдаться): D2-D3
Осталось 27 минут из 30
Ваш ход (off — сдаться): off
Осталось 27 минут из 30

Идея

1 В начале запоминаем beginning = time().
2 На каждом ходе смотрим сколько прошло: (time() - beginning).
3 Оставшееся время = 30 − прошедшее.
4 Целую часть берём через int() — чтобы показывать полные минуты.
from time import time rest = 30 move = ' ' beginning = time() while rest > 0 and move != 'off': move = input('Ваш ход (off — сдаться): ') end = time() rest = 30 - (end - beginning) / 60 print('Осталось', int(rest), 'минут из 30')
🧠 Что здесь нового

1. Условие цикла двойное: rest > 0 and move != 'off'. Цикл идёт, пока есть время И пользователь не сдался.

2. (end - beginning) / 60 — переводим секунды в минуты. Делим на 60.

3. int(rest) отбрасывает дробную часть — оставляем только целые минуты.

💡 int() vs round()

int(27.9) → 27 — просто отбрасывает хвост.
round(27.9, 0) → 28.0 — округляет до ближайшего.

Здесь нам нужно именно отбросить: если прошло 27 минут и 30 секунд, честнее показать «осталось 2 минуты», а не «3».

Изменим регламент

Заказчик поменял правила: теперь на все ходы даётся не 30 минут, а 1 час. Как переделать программу?

📖 Решение

Достаточно поменять число 30 на 60 в двух местах. Всё остальное остаётся как есть.

Код не переписывается заново — просто два числа заменяем. Именно поэтому говорят: хороший код легко менять.

01 Простое время 🌱

Выведи текущее число секунд с начала эпохи.

💡 Подсказка

Импорт: from time import time, потом print(time()).

✅ Решение 
from time import time

print(time())
02 Пауза 🌱

Выведи «Старт», подожди 3 секунды, потом выведи «Финиш».

💡 Подсказка

sleep(3) между двумя print.

✅ Решение 
from time import sleep

print("Старт")
sleep(3)
print("Финиш")
03 Замер времени 🌱🌱

Замерь, сколько секунд занимает пауза в 2 секунды. Выведи результат с двумя знаками после точки.

💡 Подсказка

start = time(); sleep(2); end = time(); print(round(end-start, 2))

✅ Решение 
from time import time, sleep

start = time()
sleep(2)
end = time()
print(round(end - start, 2))
04 Секундомер 🌱🌱

Секундомер: старт по «1», стоп по «0», вывод времени с двумя знаками.

💡 Подсказка

Два цикла while: ждём «1», потом ждём «0». Между ними — start = time().

✅ Решение 
from time import time

command = input("1 — старт: ")
while command != "1":
    command = input("1 — старт: ")
start = time()

command = input("0 — стоп: ")
while command != "0":
    command = input("0 — стоп: ")
end = time()

print("Общее время:", round(end - start, 2), "с")
05 Обратный отсчёт 🌱🌱

Выведи числа от 3 до 1 с паузой в 1 секунду между ними, потом — «Пуск!».

💡 Подсказка

Цикл for i in range(3, 0, -1), внутри — print и sleep(1).

✅ Решение 
from time import sleep

for i in range(3, 0, -1):
    print(i)
    sleep(1)

print("Пуск!")
06 Таймер на 10 секунд 🌱🌱🌱

Спрашивай у пользователя слова, пока не пройдёт 10 секунд. В конце выведи «Время вышло!».

💡 Подсказка

Запомни начало через time(), а в условии цикла проверяй time() - start < 10.

✅ Решение 
from time import time

start = time()
while time() - start < 10:
    word = input("Введите слово: ")
    print("Вы ввели:", word)

print("Время вышло!")

Сделай свою программу со временем: например, замерь скорость ввода пользователя или сделай игру на реакцию.

💡 Подсказка

Например: игра «Нажми Enter как можно скорее после сигнала». Или «Успел ли пользователь ввести ответ за 5 секунд?»
