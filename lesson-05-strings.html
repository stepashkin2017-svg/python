💡 Шаг 2 · Шесть методов строк

Магические команды для текста

У каждой строки в Python есть встроенные команды. Они называются методами. Вызываются через точку: текст.метод().

🔠 .upper() — в ВЕРХНИЙ регистр

'аня'.upper()       # 'АНЯ'

🔡 .lower() — в нижний регистр

'АНЯ'.lower()       # 'аня'

✨ .title() — Каждое Слово С Заглавной

'аня иванова'.title()   # 'Аня Иванова'

✂️ .strip() — убрать пробелы по краям

'  аня  '.strip()       # 'аня'

🔁 .replace(a, b) — заменить

'а-а-а'.replace('а', 'о')   # 'о-о-о'

📏 len(s) — длина строки

Внимание: len — это не метод, а отдельная функция. Пишется как len(текст), а не текст.len(). 

len('Аня')              # 3
⚠️ Метод не меняет исходную строку!

Строки в Python неизменяемы. Метод возвращает новую строку, а старая остаётся как была.

Хочешь изменить переменную — присвой результат обратно: name = name.strip().

🎨 Бонус: f-строки

Собирать текст из кусочков через + — неудобно. А f-строки позволяют вставлять переменные прямо в текст: 

name = 'Аня'
print(f'Привет, {name}!')   # Привет, Аня!
🐛
Хе-хе! А я спрятал три ошибки в этом коде. Попробуй их найти!
'аня'.upper — без скобок (не сработает!)
len 'аня' — забыли скобки
name.upper() — а потом удивляемся, что name не изменилось

Три уровня заданий

Начни с зелёного. Если легко — переходи к жёлтому и красному.

🟢
Привести имя в порядок

Спроси имя через input(), убери пробелы и сделай с заглавной буквы. Выведи приветствие.

Используй цепочку: input().strip().title().
Затем print(f'Привет, {name}!').
🟡
Посчитать длину имени

Спроси имя, обработай его и выведи длину через len(). Например: «Аня, в твоём имени 3 букв».

Сначала обработай имя, потом посчитай длину:
name = input(...).strip().title()
length = len(name)
🔴
Цензор

Спроси фразу, замени плохое слово на '***' через replace() и выведи результат.

phrase = input('Фраза: ')
clean = phrase.replace('плохое', '***')

Метод не меняет исходную строку — он возвращает новую. Если хочешь сохранить изменение — присвой результат обратно в переменную.
