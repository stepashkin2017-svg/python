Как хранить несколько мишеней?

Обычная переменная хранит одно значение. У нас мишеней несколько. Значит, нужен список — структура, которую мы разбирали в уроке 28.

Список объектов
Это список, элементами которого могут быть не только числа или строки, но и целые объекты — например, наши мишени. Каждый элемент — отдельный Target со своими координатами.
targets = [Target(...), Target(...), Target(...)] — список из трёх мишеней.

Знакомый список

Раньше мы хранили в списке числа: [181, 176, 160]. Теперь — объекты:

targets = [ t1, t2, t3, t4 ]
[0] Target #1
[1] Target #2
[2] Target #3
[3] Target #4

Как перебрать список мишеней

Вспомним цикл for из урока 28. Нам нужно пройти по всем мишеням — нарисовать, проверить попадание.

1 for target in targets:
Что делает

Перебирает все объекты из списка. На каждом шаге переменная target — это очередная мишень.

📖
Аналогия. Как будто мы идём по полке и по очереди берём каждую мишень: «эта мишень, эта, эта…». С каждой делаем одно и то же.
Как пишется
# создаём список мишеней targets = [] for i in range(4): t = Target(100, 100, 40) t.move_random() targets.append(t) # перебираем все мишени for target in targets: target.draw(window)
🧠 Как это работает

1. Создаём пустой список targets = [].
2. В цикле range(4) четыре раза создаём объект Target и добавляем в список через append.
3. Потом перебираем этот список и работаем с каждой мишенью отдельно.

Так можно сделать сколько угодно мишеней — хоть 100.

Проверка попадания

Когда игрок кликает, надо проверить: попал ли он в какую-нибудь из мишеней? Перебираем список:

if event.type == pygame.MOUSEBUTTONDOWN: for target in targets: if target.is_hit(event.pos): score += 1 target.move_random() break # выходим из цикла — попали в одну мишень
⚠️ Зачем break

Кликом игрок попадает только в одну мишень. Если мы не выйдем из цикла сразу — можем случайно засчитать несколько попаданий, если мишени перекрываются.

break выходит из цикла for сразу после первого попадания.

Считаем время игры

Вспомним урок 15: там мы делали секундомер через модуль time. В Pygame есть своя функция для этого — она удобнее, потому что считает миллисекунды с момента старта Pygame.

2 pygame.time.get_ticks()
Что делает

Возвращает количество миллисекунд, прошедших с момента запуска pygame.init(). Одна секунда = 1000 миллисекунд.

⏱️
Аналогия. Это как секундомер, включённый в самом начале. Он тикает всё время, пока игра работает. Мы в любой момент можем посмотреть, сколько миллисекунд прошло.
Как пишется
# узнать, сколько прошло с начала игры now = pygame.time.get_ticks() print(now) # например: 3542 (≈ 3.5 сек)

Как сделать таймер обратного отсчёта

У нас есть «всё время» в миллисекундах. Чтобы сделать обратный отсчёт, сделаем так:

1. Запоминаем момент старта в переменной.
2. На каждом кадре считаем прошедшее время: now − start.
3. Вычитаем его из 30 секунд — получаем остаток.
4. Когда остаток ≤ 0 — игра заканчивается.
start_ticks = pygame.time.get_ticks() # момент старта GAME_TIME = 30 # секунд на игру # внутри игрового цикла: seconds_passed = (pygame.time.get_ticks() - start_ticks) / 1000 time_left = GAME_TIME - seconds_passed if time_left <= 0: # время вышло! running = False # показать на экране text = font1.render('Время: ' + str(int(time_left)), True, (0, 0, 0))
🧠 Разбор

1. get_ticks() возвращает миллисекунды. Делим на 1000 — получаем секунды.
2. time_left — сколько секунд осталось.
3. Если ≤ 0 — время вышло, игра заканчивается.
4. int(time_left) — целая часть, чтобы показать «28» вместо «28.345».

⚠️ Не путай

pygame.time.get_ticks() — миллисекунды с начала работы программы. Это не дата, не текущий час, а просто «сколько прошло с запуска».

Если перезапустить игру — счёт начнётся с нуля.

⏱ 23–32 минут · 🎮 Класс Game

Упаковываем всю игру в класс

Сейчас у нас много отдельных переменных: targets, score, start_ticks, running… И каждая новая игра потребует свой набор. Пора упаковать всю игру в класс Game.

🧠 Зачем класс Game

1. Все данные игры в одном месте: мишени, счёт, время, состояние.
2. Легко сделать несколько игр с разными настройками — например, лёгкую и сложную.
3. Код становится короче: вместо десяти переменных — один объект.

Класс Game — каркас

class Game(): def __init__(self, targets_count, game_time): self.targets = [] for i in range(targets_count): t = Target(300, 250, 40) t.move_random() self.targets.append(t) self.score = 0 self.game_time = game_time self.start_ticks = pygame.time.get_ticks() self.finished = False def time_left(self): elapsed = (pygame.time.get_ticks() - self.start_ticks) / 1000 return self.game_time - elapsed def handle_click(self, pos): if self.finished: return for t in self.targets: if t.is_hit(pos): self.score += 1 t.move_random() break def update(self): if self.time_left() <= 0: self.finished = True def draw(self, surface): for t in self.targets: t.draw(surface)
class Game():
    def __init__(self, targets_count, game_time):
        self.targets = []         ← список мишеней
        self.score = 0            ← счёт игрока
        self.game_time = game_time ← сколько секунд играть
        self.start_ticks = ...     ← момент старта
        self.finished = False     ← состояние игры

    def time_left(self):       ← сколько секунд осталось
    def handle_click(self, pos): ← обработка клика
    def update(self):         ← обновление каждый кадр
    def draw(self, surface):   ← отрисовка
🧠 Разбор по шагам

1. __init__ — создаёт список мишеней через цикл range, ставит счёт 0, запоминает момент старта.

2. time_left() — возвращает, сколько секунд осталось. Считается каждый раз заново.

3. handle_click(pos) — что делать при клике. Перебирает все мишени, если попадание — +1.

4. update() — обновляет состояние (например, когда время вышло, finished = True).

5. draw(surface) — рисует все мишени.

Как играть через класс Game

import pygame from random import randint pygame.init() window = pygame.display.set_mode((600, 500)) clock = pygame.time.Clock() font1 = pygame.font.Font(None, 36) # ... классы Target и Game ... game = Game(targets_count=4, game_time=30) running = True while running: for event in pygame.event.get(): if event.type == pygame.QUIT: running = False if event.type == pygame.MOUSEBUTTONDOWN: game.handle_click(event.pos) game.update() window.fill((240, 245, 250)) game.draw(window) # счёт и таймер на экране score_text = font1.render('Очки: ' + str(game.score), True, (0, 0, 0)) window.blit(score_text, (20, 20)) time_text = font1.render('Время: ' + str(int(game.time_left())), True, (184, 50, 90)) window.blit(time_text, (420, 20)) if game.finished: end_text = font1.render('Игра окончена!', True, (180, 35, 24)) window.blit(end_text, (180, 220)) pygame.display.update() clock.tick(40) pygame.quit()

01 Список мишеней 🌱

Создай список из трёх мишеней через цикл и нарисуй их всех в игровом цикле.

💡 Подсказка

targets = [], потом цикл range(3) с append. В игровом цикле — for t in targets: t.draw(window).

✅ Решение 
import pygame
from random import randint

pygame.init()
window = pygame.display.set_mode((600, 500))
clock = pygame.time.Clock()

class Target():
    def __init__(self, x, y, radius):
        self.x = x
        self.y = y
        self.radius = radius

    def move_random(self):
        self.x = randint(80, 520)
        self.y = randint(80, 420)

    def draw(self, surface):
        pygame.draw.circle(surface, (229, 57, 53),
                           (self.x, self.y), self.radius)

targets = []
for i in range(3):
    t = Target(300, 250, 40)
    t.move_random()
    targets.append(t)

running = True
while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False

    window.fill((240, 245, 250))
    for t in targets:
        t.draw(window)
    pygame.display.update()
    clock.tick(40)

02 Попадание в любую мишень 🌱🌱

При клике перебирай список мишеней. Если попал хотя бы в одну — увеличь счёт и перепрыгни её.

💡 Подсказка

Не забудь break после попадания — чтобы не увеличить счёт несколько раз за один клик.

✅ Решение 
import pygame
from random import randint

pygame.init()
window = pygame.display.set_mode((600, 500))
clock = pygame.time.Clock()

class Target():
    def __init__(self, x, y, radius):
        self.x = x
        self.y = y
        self.radius = radius

    def is_hit(self, pos):
        mx, my = pos
        dx = mx - self.x
        dy = my - self.y
        return dx * dx + dy * dy <= self.radius * self.radius

    def move_random(self):
        self.x = randint(80, 520)
        self.y = randint(80, 420)

    def draw(self, surface):
        pygame.draw.circle(surface, (229, 57, 53),
                           (self.x, self.y), self.radius)

targets = []
for i in range(4):
    t = Target(300, 250, 40)
    t.move_random()
    targets.append(t)

score = 0

running = True
while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False
        if event.type == pygame.MOUSEBUTTONDOWN:
            for t in targets:
                if t.is_hit(event.pos):
                    score += 1
                    t.move_random()
                    break

    window.fill((240, 245, 250))
    for t in targets:
        t.draw(window)
    pygame.display.update()
    clock.tick(40)

pygame.quit()

04 Обратный отсчёт 🌱🌱

Сделай таймер обратного отсчёта: с 30 секунд до 0. Когда дойдёт до 0 — печатай «Время вышло!» один раз.

💡 Подсказка

Флаг game_over = False. Когда time_left <= 0 and not game_over — печатать и ставить True.

✅ Решение 
import pygame

pygame.init()
window = pygame.display.set_mode((600, 500))
clock = pygame.time.Clock()
font1 = pygame.font.Font(None, 80)

start_ticks = pygame.time.get_ticks()
GAME_TIME = 30
game_over = False

running = True
while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False

    elapsed = (pygame.time.get_ticks() - start_ticks) / 1000
    time_left = GAME_TIME - elapsed

    if time_left <= 0 and not game_over:
        game_over = True
        print('Время вышло!')

    window.fill((240, 245, 250))
    if not game_over:
        text = font1.render(str(int(time_left)),
                            True, (23, 32, 51))
        window.blit(text, (270, 200))
    else:
        text = font1.render('Готово!', True, (180, 35, 24))
        window.blit(text, (210, 200))
    pygame.display.update()
    clock.tick(40)

pygame.quit()
05 Класс Game 🌱🌱🌱

Упакуй игру в класс Game: список мишеней, счёт, время, состояние. Два метода — update и draw.

💡 Подсказка

В __init__ создавай мишени через цикл. update проверяет время, draw рисует все мишени.

✅ Решение 
import pygame
from random import randint

pygame.init()
window = pygame.display.set_mode((600, 500))
clock = pygame.time.Clock()

class Target():
    def __init__(self, x, y, radius):
        self.x = x
        self.y = y
        self.radius = radius

    def is_hit(self, pos):
        mx, my = pos
        dx = mx - self.x
        dy = my - self.y
        return dx * dx + dy * dy <= self.radius * self.radius

    def move_random(self):
        self.x = randint(80, 520)
        self.y = randint(80, 420)

    def draw(self, surface):
        pygame.draw.circle(surface, (229, 57, 53),
                           (self.x, self.y), self.radius)

class Game():
    def __init__(self, count, duration):
        self.targets = []
        for i in range(count):
            t = Target(300, 250, 40)
            t.move_random()
            self.targets.append(t)
        self.score = 0
        self.duration = duration
        self.start_ticks = pygame.time.get_ticks()
        self.finished = False

    def time_left(self):

from random import randint

    def __init__(self, x, y, radius):

        self.y = y
