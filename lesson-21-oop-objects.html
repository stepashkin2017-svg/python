Объект
Это «штука», у которой есть что-то, что она помнит о себе, и что-то, что она умеет делать. В программировании эти части называют по-умному, но смысл — именно такой.
Собака — объект. Она помнит, что её зовут Рекс (это её свойство), и умеет лаять (это её метод).
🧠 Давай запомним два слова

Свойство — это то, что объект помнит. Для черепашки — её цвет, координаты, скорость.

Метод — это то, что объект умеет делать. Для черепашки — двигаться вперёд, поворачивать, менять цвет.

Как посмотреть на анатомию объекта

Представим объект «Черепашка Т1» на карточке:

🔴 Свойства (помнит)
цвет = 'red'
x = -200
y = -20
🟢 Методы (умеет)
t1.forward(10)
t1.left(90)
t1.color('blue')

Точка — это «покажи мне, что там внутри»

Чтобы обратиться к свойству или методу объекта, используют точку. Она как бы говорит: «посмотри внутрь этой штуки и возьми оттуда вон то».

t1.color('red') # метод: покрась себя в красный t1.forward(10) # метод: шагни вперёд на 10 # (до этой строки мы ещё доберёмся — но у черепашки есть и такое) x = t1.xcor() # свойство: скажи, где ты сейчас по X
⚠️ Читаем правильно

t1.forward(10) читается так: «Обратись к объекту t1, попроси его сделать forward с числом 10».

Точка — как «кнопка» или «дверь» в объект: без неё Python не поймёт, что мы хотим именно от черепашки, а не от чего-то другого.

Что помнит и что умеет черепашка

У черепашки-объекта есть свойства и методы. Разберём самые полезные — именно они понадобятся нам в игре.

Методы, которые мы уже знаем

Все команды, которые мы использовали раньше — это методы черепашки. Просто раньше мы обращались к «самой главной» черепашке, а её имя было скрыто. Теперь у каждой черепашки будет своё имя, и мы будем писать имя.метод().

РаньшеТеперьЧто делает
forward(50) t1.forward(50) Идти вперёд на 50 пикселей
left(90) t1.left(90) Повернуть налево на 90°
color('red') t1.color('red') Стать красного цвета
goto(0, 0) t1.goto(0, 0) Перейти в точку (0, 0)
🧠 Всё то же самое, только с именем

Раньше: forward(50) — «черепашка, иди вперёд». Теперь: t1.forward(50) — «черепашка t1, иди вперёд».

Так мы говорим Python, какая именно черепашка должна выполнить команду. Если черепашек две, три, десять — каждая слушается только своих команд.

Новые методы: форма и координата

Для игры «Черепашьи гонки» нам понадобятся два новых метода.

1. shape() — как выглядит черепашка

По умолчанию черепашка — просто стрелочка. Но можно поменять её «костюм»:

t1.shape('turtle') # стань черепашкой

Доступные костюмы:

Что писатьКак выглядит
'arrow'Стрелочка (по умолчанию)
'turtle'Черепашка
'circle'Кружок
'square'Квадрат
'triangle'Треугольник
'classic'Классическая стрелка

Для игры «Черепашьи гонки» логично поставить черепашкам костюм 'turtle'. Тогда будет понятно, кто бежит.

2. xcor() — где сейчас черепашка

Метод xcor() возвращает координату X черепашки — то есть насколько она далеко по горизонтали. Это нам понадобится, чтобы понять, кто добрался до финиша.

x = t1.xcor() # узнать, где черепашка по горизонтали print(x) # например: 150
🧠 Как это использовать

Сравниваем координату черепашки с финишной чертой:

if t1.xcor() < 200: — если ещё не дошла, пусть бежит дальше.

if t1.xcor() >= 200: — финиш!

И ещё одна полезная функция

Чтобы определить победителя, нам нужно найти максимум из двух координат. Для этого есть встроенная функция max():

победитель_x = max(t1.xcor(), t2.xcor()) # вернёт большую из двух координат
🧠 Функция max()

max() принимает несколько чисел и возвращает самое большое. Можно передать два числа, три, десять — сколько угодно.

max(5, 3) → 5
max(-2, 7, 4) → 7

⏱ 22–32 минут · 🐢 Несколько черепашек

Создаём несколько объектов

Теперь самое интересное: как сделать сразу несколько черепашек в одной программе. Это проще, чем кажется!

Одна черепашка

Раньше мы писали from turtle import * — и получали готовую черепашку «без имени». Она выполняла наши команды, но обращаться к ней самой было нельзя.

Своя черепашка с именем

Чтобы сделать собственную черепашку, используют класс Turtle (пишется с большой буквы). Смотри:

from turtle import * t1 = Turtle() t1.color('red') t1.forward(100) t2 = Turtle() t2.color('blue') t2.forward(100)
🧠 Что здесь произошло

1. Turtle() — «создай мне новую черепашку». Слева от неё мы пишем имя переменной: t1 = Turtle(). Теперь у нас есть черепашка с именем t1.

2. Вторая строка t2 = Turtle() — создаём ещё одну черепашку, независимую.

3. Теперь у нас две черепашки, у каждой свои свойства (цвет, координата) и свои методы.

Сколько угодно черепашек!

В Python можно создать хоть десять черепашек. Каждая будет помнить свой цвет, свою позицию и слушаться только своих команд:

from turtle import * t1 = Turtle() t1.color('red') t1.forward(100) t2 = Turtle() t2.color('green') t2.forward(80) t3 = Turtle() t3.color('blue') t3.forward(120)

⏱ 32–40 минут · 🏁 Гонки

Программируем «Черепашьи гонки»

Теперь мы готовы собрать игру. Разберём её по шагам, как план: подготовка черепашек → гонка → победный танец.

План игры

1 Подготовка. Создать двух черепашек, задать им цвет, форму и стартовые позиции.
2 Гонка. Пока ни одна из черепашек не дошла до финиша — двигать их вперёд на случайное число пикселей.
3 Финал. Определить победителя и запустить победный танец.

Шаг 1. Подготовка черепашек

Создадим двух черепашек и поставим их на старт. Удобно написать для этого небольшую функцию:

def start_race(t, x, y, color): t.color(color) t.shape('turtle') t.penup() t.goto(x, y) t.pendown() t1 = Turtle() t2 = Turtle() start_race(t1, -200, -20, 'red') start_race(t2, -200, 20, 'blue')
🧠 Что мы сделали

Функция start_race получает черепашку и её параметры (координаты, цвет). Так одна и та же функция настраивает и первую, и вторую черепашку.

Заметь: первым параметром мы передаём сам объект. Внутри функции он называется t, а снаружи это t1 или t2.

Шаг 2. Сама гонка

Гонка — это цикл, который работает, пока хотя бы одна черепашка не добралась до финиша. На каждой итерации каждая черепашка шагает вперёд на случайное число от 2 до 7 пикселей.

finish = 200 while t1.xcor() < finish and t2.xcor() < finish: t1.forward(randint(2, 7)) t2.forward(randint(2, 7))
🧠 Разбор по шагам

1. finish = 200 — на какой координате заканчивается дорожка.
2. Условие цикла: обе черепашки ещё не дошли. Значит, шагаем ещё.
3. На каждом шаге каждая черепашка бежит на случайное число пикселей — то быстрее, то медленнее.

Цикл остановится, когда хотя бы одна черепашка пересечёт координату 200.

Шаг 3. Определяем победителя

Победит та черепашка, у которой координата больше. Вспоминаем функцию max():

max_x = max(t1.xcor(), t2.xcor()) if max_x == t1.xcor(): print('Победила красная черепашка!') winner = t1 else: print('Победила синяя черепашка!') winner = t2

Шаг 4. Победный танец

Победитель может станцевать — покружиться на месте. Это делает игра веселее:

def dance(t): t.penup() t.goto(0, 0) t.pendown() for i in range(8): t.forward(20) t.left(45) dance(winner)
🧠 Функция принимает черепашку

Обрати внимание: dance(t) принимает черепашку как параметр. Значит, можно запустить танец для любой — например, только для победителя.

Внутри функции мы вызываем методы у объекта t: t.forward(), t.left(). Это тот же приём, что и со start_race.

07 Мини-гонка 🌱🌱🌱

Сделай упрощённую версию «Черепашьих гонок»: две черепашки на одной линии, бегут, пока одна не дойдёт до финиша. Определи победителя через max().

💡 Подсказка

Используй randint(2, 7) для скорости, цикл while и условие по xcor().

✅ Решение 
from turtle import *
from random import randint

finish = 200

t1 = Turtle()
t1.color('red')
t1.shape('turtle')
t1.penup()
t1.goto(-200, 20)
t1.pendown()

t2 = Turtle()
t2.color('blue')
t2.shape('turtle')
t2.penup()
t2.goto(-200, -20)
t2.pendown()

while t1.xcor() < finish and t2.xcor() < finish:
    t1.forward(randint(2, 7))
    t2.forward(randint(2, 7))

max_x = max(t1.xcor(), t2.xcor())
if max_x == t1.xcor():
    print("Победила красная!")
else:
    print("Победила синяя!")

exitonclick()
